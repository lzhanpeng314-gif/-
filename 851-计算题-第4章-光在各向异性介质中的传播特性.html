这一章只考四件事：① 折射定律把一束光拆成两支；② δ = 2πΔn·dλ 定偏振态； ③ 离散角 α 求两束光间距；④ KDP 纵向电光：半波电压 Uπ = λ2n03γ63。 十道题里九道是这四个式子的排列组合，剩下一个是渥拉斯顿棱镜的连续两次折射。
双折射·折射定律
n1 sini = no sinro = ne(θ) sinre
光轴 ⊥ 入射面（或光线 ⊥ 光轴）时 ne(θ) = ne 取主值；否则用 1ne2(θ) = cos2θno2 + sin2θne2，θ 是波法线与光轴的夹角。
相位差 · 波片判据
δ = 2πλ(n慢 − n快)d
δ = π/2 → 1/4 波片；δ = π → 1/2 波片；δ = 2π → 全波片。只看 Δn·d/λ 的小数部分。
离散角（光轴与法线成 θ）
tanα = sinθcosθ(ne2 − no2)no2sin2θ + ne2cos2θ
母光沿法线时，e 光走这偏角；出射面仍平行，两光间距 s = d tanα。
KDP 纵向电光
δ = 2πλn03γ63U，Uπ = λ2n03γ63
纵向运用 E = U/l，长度 l 约掉，δ 只与电压有关。γ63(KDP) = 10.6×10−12 m/V = 10.6×10−10 cm/V。
本章大点 · 偏振态判定（所有区块共用）
  • 只看两件事：两分量的相位差 δ，以及振幅比 A⊥/A∥。合成轨迹由这两个量唯一确定。
条件偏振态
δ = 0 或 ±π线偏振（振动方向由振幅比定）
δ = ±π/2 且 A⊥ = A∥圆偏振
其余情况椭圆偏振（主轴方位、轴比由 δ 与振幅比共同定）
  • 旋向：迎着光看，向右为 x、向上为 y，δ = φy−φx；δ∈(0,π) → 右旋，δ∈(−π,0) → 左旋。
  • 标准动作：① 分解到快、慢轴 → ② 慢轴落后 δ=2π|n慢−n快|d/λ → ③ 合成、查表。
  • 波片速查：λ/4 → 线↔圆；λ/2 → 线仍是线、转 2α；全波片 → 不变。
  • 翻转判据：加波片后 δ 变为 δ+Δ，只有越过 0 或 ±180° 才翻转旋向。分量取负号等于加 π，会翻转。

A · 折射定律与双折射
  • 折射定律管波法线，不是光线方向
  • 负晶体（ne<no）e 光线远离光轴
tanφ = (no2/ne2)tanθ
tanα = 12sin2θ(1no2−1ne2)(cos2θno2+sin2θne2)−1
折射定律来自界面上的相位连续，所以它约束波法线；能流方向另由边界条件定，两者在晶体里才分家。
题面都带"画图"，但真正要算的只有一个数：两支光在晶体里走不同角度，出射面上就分开一段距离。
A · 波片作用表 + 快慢轴判据（背这张表就够）
波片δ厚度线偏振入射（振动与光轴夹角 α）→ 出射
1/4 波片π/2λ/(4Δn)α = 45° ⇒ 圆偏振；其他 α ⇒ 椭圆（长轴沿光轴或垂直光轴）；α = 0°/90° ⇒ 不变
1/2 波片πλ/(2Δn)仍线偏振，振动方向相对光轴镜像 ⇒ 转过 2α（α=45° 时转 90°）
全波片2πmmλ/Δn不变（偏振态、方向都不变）
  • 相位差通式 δ = 2π|ne−no|d/λ（光轴平行于表面、正入射）；光轴与表面成 45° 时要用有效折射率 ne(θ)，不能直接用 ne。
  • 快慢轴：负晶体（ne < no，如方解石）光轴是快轴；正晶体（ne > no，如石英）光轴是慢轴。判断旋向时先定快慢轴再定谁超前。
  • 一块片对另一波长的效果：δ2/δ1 = (Δn′/Δn)·(λ1/λ2)，比例算最快（2019-二-4 就是这招）。

原卷无图：机构资料在这里配了一张三棱镜图，与“平行平板”的题干矛盾，已删除。下面是按本题条件重画的。光轴 ⊥ 入射面 ⇒ 波法线与光轴恒成 90°，ne(θ) 恒等于 ne、无离散角，两束只是折射角不同。
1先把"折射率取哪个值"定下来：光轴垂直于入射面，晶体里两支光的波法线始终在入射面内，与光轴恒成 90°，所以 o 光用 n0、e 光用主值 ne，且 e 光不走出离（波法线方向 = 光线方向）。
2掠入射即 i = 90°，sini = 1，故 sinr = 1/n
sinro = 11.525 = 0.6557 ⇒ ro = 40.98°；　sinre = 11.479 = 0.6761 ⇒ re = 42.54°
3两支光从同一点射入，各自沿 ro、re 走到第二面（垂直距离 d = 5 cm = 50 mm），在第二面上的落点相距
Δ = d(tanre − tanro) = 50 × (0.9177 − 0.8685) = 2.46 mm
4出射面仍是同一块平板，n sinr = sini′ ⇒ sini′ = 1，两支光都以 90° 掠着第二面出射，方向与第二面平行，故二者离开晶体后互相平行。画光路图时：入射光擦着第一面射入，晶体里两条线分别与法线成 40.98°、42.54°，到第二面各折成沿面方向。
第二面上两出射点相距 2.46 mm；出射后两光均沿第二面掠出、彼此平行；o 光偏折小于 e 光（ro < re，因为 n0 > ne）。题干问"在第二个面上二光分开的距离"，故沿第二面量（2.46 mm）；若改成正光线之间的间距，掠出时会退化为 0，那不是题意。

2021-二-5方解石直角棱镜：只让一种线偏振光射出，顶角 α 取多大
如图所示，一方解石 n0 = 1.6548，ne = 1.4864 直角棱镜，光轴平行于直角棱，自然光垂直入射。要使出射光只有一种线偏振光，另一种被完全反射掉。
（1）顶角 α 应取什么范围；（2）画出光路并标上反射光和透射光的振动方向。
图

（1）

1几何关系：入射光垂直入射面 ⇒ 在棱镜内沿水平方向前进，斜边法线与水平方向成 α，所以斜面上的入射角 θ = α（题图里 θ 正是这个角）。
2光轴平行于直角棱（截面内竖直，与光线垂直），故两支光都用主折射率：o 光（振动 ⊥ 主截面，即 ⊥ 纸面）用 n0，e 光（振动在主截面内、∥ 光轴）用 ne。全反射临界角
sinCo = 11.6548 = 0.6043 ⇒ Co = 37.2°；　sinCe = 11.4864 = 0.6728 ⇒ Ce = 42.3°
3要求"一种全反射、另一种能透射"，即入射角落在两个临界角之间
Co < α < Ce　⇒　37.2° < α < 42.3°

α 若 > 42.3°，两支全反射，没有出射光；α 若 < 37.2°，两支都透射，出射仍是自然光的混合。

4取 α = 40° 验算：n0 sin40° = 1.064 > 1，o 光全反射；ne sin40° = 0.9554，e 光折射角 arcsin0.9554 = 72.8° 掠射出去。

（2）

5光路：o 光在斜面上按反射定律反向射回棱内（反射角 = α），e 光偏折后从斜面射出、方向几乎贴着斜面（72.8°）。振动方向：反射的 o 光振动 ⊥ 纸面；透射的 e 光振动在纸面内、平行于光轴。
顶角取 37.2° < α < 42.3°（即 arcsin(1/1.6548) < α < arcsin(1/1.4864)）；此时 o 光全反射、e 光透射，出射光为单一 e 光线偏振。
易错：① 入射角在斜面上等于 α，不是 90°−α —— 因为光线垂直入射面、斜边法线与光线成 α；② 谁全反射看的是"哪个折射率小"，ne 小 ⇒ 临界角大 ⇒ e 光透射。若题图把光轴画成垂直纸面，则两支光的 o/e 名称互换（角度范围不变）。

B · 单轴晶体中的传播
  • o 光振动 ⊥ 主截面；e 光在主截面内
  • 沿光轴不分开，⊥ 光轴分开最大
δ = 2πλ|ne(θ)−no|d
θ=0 时 ne(θ)=no，两支折射率相同自然不分开——这就是沿光轴不发生双折射的来历。
这一组是"波片 + 偏振态"：先算 δ = 2πΔnd/λ 折成 π 的几倍，再看入射振幅比，最后判圆/椭圆/线。

D · 波片1 题

D · 波片
  • δ = π/2 为 λ/4，δ = π 为 λ/2，δ = 2π 为全波片
  • 折射率大的是慢轴
  • 线偏振过 λ/2 → 转 2α
δ = 2πλ|no−ne|d
波片题的坑在"对谁而言是几号波片"：同一块片子，对不同波长 δ 不一样（色散）。
2019-二-4λ1 的 1/4 波片对 λ2 是什么波片
已知方解石对波长 λ1 = 405 nm 光波的主折射率为 no = 1.6813，ne = 1.4969；对波长 λ2 = 710 nm 光波的主折射率为 no′ = 1.6521，ne′ = 1.4836。若一束波长为 λ2 的左旋正椭圆偏振光入射到相应于波长为 λ1 的方解石 1/4 波片上，求：（1）λ1 光波通过该波片时，所产生的相位差？（2）对于 λ2 光波而言，判断该波片是哪种波片？（3）出射光束的偏振态？

（1）

1定义就是答案：既然它是"对 λ1 的 1/4 波片"，则 λ1 通过时的相位差
δ1 = 2πλ1(no − ne)d = π2 = 90°，　且 (1.6813 − 1.4969)d = 4054 nm = 101.25 nm
⇒ d = 101.25 nm0.1844 = 549.1 nm

（2）

2同一块片对 λ2：
δ2 = 2πλ2(no′ − ne′)d = 2π710×10−9 × 0.1685 × 549.1×10−9 = 2π × 0.1303 = 0.819 rad = 46.9°

也可用比例一步算：δ2/δ1 = Δn′Δn · λ1λ2 = (0.1685/0.1844)(405/710) = 0.521 ⇒ δ2 = 0.521 × 90° = 46.9°。

3判据：46.9° 既不是 90°（1/4 波片）也不是 180°（1/2 波片）、更不是 360°。对 λ2 而言它只是一块"任意波片"，光程差 0.13λ（相当于约 1/8 波片，介于 1/8 与 1/4 之间）。

（3）

4入射为正椭圆——椭圆主轴恰沿 o、e 振动方向，这要求 δin = ±90°。叠加该片 46.9°：δout = δin + 46.9°。
左旋 ⇒ δin = −90°，δout = −43.1°，符号未变 ⇒ 旋向不变，仍是左旋。
因 δout ≠ ±90°，主轴不再沿 o/e，转过一个角度、轴比也变；具体取决于入射椭圆轴比（题未给），只能定性。
通用规律：加波片后 δ → δ+Δ，只有越过 0 或 ±180° 才翻转旋向。
（1）δ1 = 90°（d = 549.1 nm）；（2）对 λ2 它不是 1/4 波片，只是一块 δ ≈ 46.9° 的任意波片（光程差 0.13λ）；（3）出射仍为左旋椭圆偏振光（δout = −43.1°，符号未变），主轴方向不变、轴比改变。"正椭圆"指主轴沿晶体两主轴的椭圆。入射是正椭圆 ⇒ 出射仍是正椭圆，主轴方向不变，只有轴比随 δout 改变、旋向不变（δout = −43.1°，符号未变）。若入射其实是圆偏振（轴比 1），则总相位差 90°+47° = 137°、轴比 |tan(137°/2)|−1 ≈ 0.39、长轴与 x 成 45°。
符号到底怎么定？（容易绕晕的地方）
① δ 的定义随你便，但要一次定死：取“迎着光看、右为 x、上为 y”，δ = φy−φx。若你把两轴对调，δ 反号、左/右旋的标签也同时反号，物理结论不变——所以“谁减谁”本身不需要猜。
② “正椭圆”给出的只有大小：主轴沿 o、e ⇒ |δin| = 90°，具体是 +90° 还是 −90°，由“左旋/右旋”这句话决定（左旋 ⇒ δin = −90°）。
③ 波片加的是“慢轴落后 Δ”：Δ = 2π|n慢−n快|d/λ。写成 δ 时要按你选的轴决定是 +Δ 还是 −Δ，但——
④ 本题不需要这个符号：|δin| = 90°，|Δ| = 46.9° < 90°，无论加还是减，δout 都落在 (−180°, 0°) 内，符号不可能翻。这就是“旋向不变”的依据。
⑤ 会翻的情况：|Δ| ≥ |δin| 且方向使 δ 越过 0（如 λ/4 片遇上 ±90° 入射 → δ=0 变线偏振；λ/2 片 Δ=180° → 必翻）。

E · 偏光干涉（平行光的偏光干涉）—— 公式 + 两条判据（推导略）
装置与记号：起偏器 P₁ → 晶片（厚 d，两主折射率 n′、n″）→ 检偏器 P₂。α = 起偏器与晶体主轴的夹角，β = P₁ 与 P₂ 偏振轴的夹角。
图 · 装置与振动分量（点此收起）
E′ = E₀cosα　，　E″ = E₀sinα　，　φ = 2πλ(n′−n″)d
I = I₀[cos²α·cos²(α−β) + sin²α·sin²(α−β) + 2cosα·cos(α−β)·sinα·sin(α−β)·cosφ] ≡ I₀[cos²β − sin2α·sin2(α−β)·sin²(φ/2)]
正交（β = 90°）：I⊥ = I₀ sin²2α·sin²(φ/2)　；　平行（β = 0）：I∥ = I₀[1 − sin²2α·sin²(φ/2)]
  • 消光（正交时 I⊥ = 0）只有两种可能：α = 0°/90°（主轴与起偏器重合、光不被分解），或 φ = 2mπ（整波片）。
  • 最亮（I⊥ = I₀）：α = 45° 且 φ = (2m+1)π —— 「正交偏振器 + 45° 半波片 = 全通」就是这么来的。
  • 白光入射：φ 随 λ 变 ⇒ 各色干涉强度不同 ⇒ 出射带彩色；转动晶片或检偏器颜色随之变（偏光显微镜、光测弹性的基础）。
  • 判据一句话：φ ≠ 2mπ 且 α ≠ 0°/90° 时，正交偏振器下就有光通过，亮度按 sin²(φ/2) 随 φ 周期变化。
  • 与波片的关系：全波片 φ = 2mπ ⇒ 正交下仍消光；半波片 φ = (2m+1)π ⇒ 45° 放置时正交变全通（检偏器相当于被"转"了 90°）。

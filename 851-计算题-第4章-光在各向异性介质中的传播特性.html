旋向判定标准（记住这一条就够）　第一步·定轴：让光朝你射来（观察者迎着光），取向右为 x、向上为 y，此时 x × y 恰指向你。δ 只能用这两个轴算：δ = φ上 − φ右。轴名取错，结论必反。　第二步·判据：0 < δ < π → 右旋（E 顺时针）；−π < δ < 0 → 左旋（逆时针）。速记 +90° → 右旋，−90° → 左旋。　为什么老乱：① 有些书写"沿传播方向看"，结论整体反过来；② 复数式 Ey/Ex = e±iπ/2 的正负取决于时间因子取 eiωt 还是 e−iωt，各书不一，别背 ±i；③ 最要命的是轴名——同一束光，x、y 换个叫法，δ 就变号。　零风险判法：写出 E右 = A cos(ωt)、E上 = A cos(ωt + δ)，代 ωt = 0° 与 30° 各画一个箭头，顺时针即右旋。不用记任何符号。

这一章只考四件事：① 折射定律把一束光拆成两支；② δ = 2πΔn·dλ 定偏振态； ③ 走离角 ρ 求两束光间距；④ KDP 纵向电光：半波电压 Uπ = λ2n03γ63。 十道题里九道是这四个式子的排列组合，剩下一个是渥拉斯顿棱镜的连续两次折射。
旋向约定（全文统一）：迎着光的传播方向看（光冲你而来），E 逆时针转记作左旋，顺时针记作右旋； 相位差 δ = φe − φo 取"慢光超前为正"。有些教材正好相反，若你的约定相反，把"左旋/右旋"互换即可，数值结论不变。
双折射·折射定律
n1 sini = no sinro = ne(θ) sinre
光轴 ⊥ 入射面（或光线 ⊥ 光轴）时 ne(θ) = ne 取主值；否则用 1ne2(θ) = cos2θno2 + sin2θne2，θ 是波法线与光轴的夹角。
相位差 · 波片判据
δ = 2πλ(n慢 − n快)d
δ = π/2 → 1/4 波片；δ = π → 1/2 波片；δ = 2π → 全波片。只看 Δn·d/λ 的小数部分。
走离角（光轴与法线成 θ）
tanρ = sinθcosθ(ne2 − no2)no2sin2θ + ne2cos2θ
母光沿法线时，e 光走这偏角；出射面仍平行，两光间距 s = d tanρ。
KDP 纵向电光
δ = 2πλn03γ63U，Uπ = λ2n03γ63
纵向运用 E = U/l，长度 l 约掉，δ 只与电压有关。γ63(KDP) = 10.6×10−12 m/V = 10.6×10−10 cm/V。

A · 折射定律与双折射画图3 题

题面都带"画图"，但真正要算的只有一个数：两支光在晶体里走不同角度，出射面上就分开一段距离。
2020-二-4掠入射 5 cm 单轴平板，第二面上二光分开多远
一细光束掠入射厚度为 5 cm 的单轴晶体平行平板，晶体的光轴与入射面垂直。若 n0 = 1.525，ne = 1.479，试计算在第二个面上输出二光分开的距离，并绘出光路图。
原卷图 · 可收起
1先把"折射率取哪个值"定下来：光轴垂直于入射面，晶体里两支光的波法线始终在入射面内，与光轴恒成 90°，所以 o 光用 n0、e 光用主值 ne，且 e 光不走出离（波法线方向 = 光线方向）。
2掠入射即 i = 90°，sini = 1，故 sinr = 1/n
sinro = 11.525 = 0.6557 ⇒ ro = 40.98°；　sinre = 11.479 = 0.6761 ⇒ re = 42.54°
3两支光从同一点射入，各自沿 ro、re 走到第二面（垂直距离 d = 5 cm = 50 mm），在第二面上的落点相距
Δ = d(tanre − tanro) = 50 × (0.9177 − 0.8685) = 2.46 mm
4出射面仍是同一块平板，n sinr = sini′ ⇒ sini′ = 1，两支光都以 90° 掠着第二面出射，方向与第二面平行，故二者离开晶体后互相平行。画光路图时：入射光擦着第一面射入，晶体里两条线分别与法线成 40.98°、42.54°，到第二面各折成沿面方向。
第二面上两出射点相距 2.46 mm；出射后两光均沿第二面掠出、彼此平行；o 光偏折小于 e 光（ro < re，因为 n0 > ne）。【待核】掠入射时出射光严格平行于第二面，若把"二光分开的距离"理解为垂直于光线的间距，则退化为 0；本页按"沿第二面量"的口径给出 2.46 mm。

2021-二-5方解石直角棱镜：只让一种线偏振光射出，顶角 α 取多大
如图所示，一方解石 n0 = 1.6548，ne = 1.4864 直角棱镜，光轴平行于直角棱，自然光垂直入射。要使出射光只有一种线偏振光，另一种被完全反射掉。
（1）顶角 α 应取什么范围；（2）画出光路并标上反射光和透射光的振动方向。
原卷图 · 可收起

（1）

1几何关系：入射光垂直入射面 ⇒ 在棱镜内沿水平方向前进，斜边法线与水平方向成 α，所以斜面上的入射角 θ = α（题图里 θ 正是这个角）。
2光轴平行于直角棱（截面内竖直，与光线垂直），故两支光都用主折射率：o 光（振动 ⊥ 主截面，即 ⊥ 纸面）用 n0，e 光（振动在主截面内、∥ 光轴）用 ne。全反射临界角
sinCo = 11.6548 = 0.6043 ⇒ Co = 37.2°；　sinCe = 11.4864 = 0.6728 ⇒ Ce = 42.3°
3要求"一种全反射、另一种能透射"，即入射角落在两个临界角之间
Co < α < Ce　⇒　37.2° < α < 42.3°

α 若 > 42.3°，两支全反射，没有出射光；α 若 < 37.2°，两支都透射，出射仍是自然光的混合。

4取 α = 40° 验算：n0 sin40° = 1.064 > 1，o 光全反射；ne sin40° = 0.9554，e 光折射角 arcsin0.9554 = 72.8° 掠射出去。

（2）

5光路：o 光在斜面上按反射定律反向射回棱内（反射角 = α），e 光偏折后从斜面射出、方向几乎贴着斜面（72.8°）。振动方向：反射的 o 光振动 ⊥ 纸面；透射的 e 光振动在纸面内、平行于光轴。
顶角取 37.2° < α < 42.3°（即 arcsin(1/1.6548) < α < arcsin(1/1.4864)）；此时 o 光全反射、e 光透射，出射光为单一 e 光线偏振。
易错：① 入射角在斜面上等于 α，不是 90°−α —— 因为光线垂直入射面、斜边法线与光线成 α；② 谁全反射看的是"哪个折射率小"，ne 小 ⇒ 临界角大 ⇒ e 光透射。若题图把光轴画成垂直纸面，则两支光的 o/e 名称互换（角度范围不变）。

2024-二-5方解石薄片：垂直入射与 60° 斜入射后，出射光的偏振
如图所示为一方解石晶体 n0 = 1.5246，ne = 1.4792，d = 0.01 mm，光轴方向如图所示，入射波长 λ = 550 nm，线偏振光入射的偏振角度为 45°，求出射后的光波偏振方向；当入射夹角为 60° 时，求出射后的光波偏振方向。

（1）垂直入射

1光轴 ⊥ 纸面、光线在纸面内 ⇒ 光线与光轴垂直。o 光振动在纸面内（图中竖直），e 光振动 ⊥ 纸面（沿光轴），二者都取主折射率。
2累计相位差
δ = 2πλ(n0 − ne)d = 2π550×10−9 × 0.0454 × 1.0×10−5 = 5.19 rad = 297° = 0.825×2π

n0 > ne（负晶体）⇒ o 光慢，e 光超前 o 光 297°（等价于 o 超前 63°）。

3入射振动与两支光成 45° ⇒ 两分量等幅。等幅 + 相位差 0.825×2π，出射是椭圆偏振光，椭圆主轴与 o、e 振动方向各成 45°；半轴比（用 Eo = Ee = A）：
a = A√(1+|cosδ|) = 1.207A，b = A√(1−|cosδ|) = 0.737A　⇒　ba = 0.61　（cosδ = cos297° = 0.457）

（2）入射角 60°

4此时光轴仍 ⊥ 入射面，两支光波法线都在入射面内、与光轴成 90°，所以仍用主折射率，按折射定律分开
sin60° = n0 sinro ⇒ ro = arcsin0.86601.5246 = 34.6°；　sin60° = ne sinre ⇒ re = 35.8°
5两支光在晶体内分开 1.2°，走完 d 后从平行的第二面射出，各自折射回与入射方向平行；因此出射是两束平行的线偏振光：o 光振动 ⊥ 入射面（⊥ 纸面），e 光振动在入射面内，两者振动方向互相垂直。
垂直入射：出射为椭圆偏振光（δ = 297° ≈ 0.825×2π，椭圆主轴与 o、e 振动方向成 45°，轴比 0.61，左旋）。
60° 斜入射：进入晶体时分成 o、e 两支（ro = 34.6°、re = 35.8°），出射为两束平行线偏振光、振动方向互相垂直，偏振方向不再旋转。
口径说明：题面两处都写"偏振方向"，但垂直入射的情形按相位差算出来是椭圆偏振，只能给"偏振态 + 椭圆主轴方位"。这一点与真题答案册的口径一致（答案册给出"φ = k(ne − no)d、椭圆偏振、以及 60° 时 n sin60° = no sinθo = ne sinθe"）；但答案册写"o 光超前 e 光"与本页相反 —— 方解石 ne < no，e 光快，应为 e 超前，本页按物理事实写。

B · 光在单轴晶体中的传播3 题

这一组是"波片 + 偏振态"：先算 δ = 2πΔnd/λ 折成 π 的几倍，再看入射振幅比，最后判圆/椭圆/线。
2018-二-50.05 mm 石英晶片：45° 入射的出射偏振态、是几号波片
如图所示，一束线偏振光（λ = 600 nm）垂直通过厚度为 0.05 mm 的石英晶片，晶片折射率为 n0 = 1.544，ne = 1.553，光轴沿 x 轴方向。（1）求线偏振光的振动方向与 x 轴夹角为 45° 时，出射光的偏振态。（2）该晶片相当于何种波片？其快、慢轴在哪个方向？
原卷图 · 可收起

（1）

1石英 ne > n0（正晶体）。光垂直入射、光线 ⊥ 光轴：沿 x（光轴）振动的是 e 光，慢；沿 y 振动的是 o 光，快。
2
Δn·dλ = (1.553 − 1.544) × 0.05×10−3600×10−9 = 4.5×10−76.0×10−7 = 0.75
δ = 2π × 0.75 = 1.5π = 270°
345° 入射 ⇒ Ex = Ey = A；两支光相位差 270°（等价 −90°），等幅 + |δ| = 90° ⇒ 振幅合成轨迹是圆
Ex = Acos(ωt − 270°) = −Asinωt，Ey = Acosωt　⇒　Ex2 + Ey2 = A2

t = 0 时指向 +y，之后转向 −x：迎着光看是逆时针 ⇒ 左旋圆偏振光。

（2）

4Δn·d = 0.75λ ⇒ 光程差 3λ/4，相位差 3π/2，故是 3/4 波片（= −1/4 波片）。
5慢轴在折射率大的振动方向：慢轴 ∥ x（光轴），快轴 ∥ y。
（1）出射为左旋圆偏振光（δ = 270°，等幅两分量）；（2）该晶片是 3/4 波片（光程差 0.75λ），慢轴沿 x（光轴）、快轴沿 y。

（2）

C · 偏振棱镜1 题

渥拉斯顿棱镜的套路：两棱镜光轴互相垂直 ⇒ 同一支光在两半里的折射率互换，在斜面上"一大一小"各折一次，夹角就出来了。
2017-二-4渥拉斯顿棱镜（45° 方解石）：ADC 中两光夹角
如图所示为渥拉斯顿棱镜的截面，由两块棱角均为 45° 的直角方解石棱镜粘合其斜面而构成，两直角棱镜的光轴如图所示，方解石的主折射率为 n0 = 1.658，ne = 1.486，当自然光垂直 AB 面入射时，（1）分析说明光在两直角棱镜中的传播情况，并画出光在两棱镜中的光路和离开 DC 面时的光路，标示出相应光矢量的振动方向；（2）求出直角棱镜 ADC 中光的夹角。
原卷图 · 可收起

（1）

1第一半 ABC：光轴竖直、光水平入射 ⇒ 光线 ⊥ 光轴，两支光各按主折射率直进、无走离。e 光（振动在主截面内、竖直）ne = 1.486，o 光（振动 ⊥ 纸面）n0 = 1.658。
2第二半 ADC：光轴垂直纸面。原来在纸面内振动的光（ABC 中的 e 光）现在变成 o 光（n0）；原来 ⊥ 纸面振动的光（ABC 中的 o 光）变成 e 光（ne）。即两支光在斜面上折射率互换。
3斜面 AC 上入射角 45°（AC 与 AB 成 45°）。一支从 n0 → ne（由密到疏），另一支 ne → n0（由疏到密）：
1.658 sin45° = 1.486 sinr1 ⇒ r1 = 52.09°；　1.486 sin45° = 1.658 sinr2 ⇒ r2 = 39.33°
4换算成相对原入射方向（法线与入射方向成 45°）
第一支偏 r1 − 45° = 7.09°（向下）；第二支偏 45° − r2 = 5.67°（向上）
ADC 内夹角 Δ = 7.09° + 5.67° = 12.76°

（2）

5出 DC 面（法线水平）时的入射角就是各自的偏角，再折射一次
sini1′ = 1.486 sin7.09° = 0.1834 ⇒ 10.57°；　sini2′ = 1.658 sin5.67° = 0.1638 ⇒ 9.43°
出射后两光夹角 ≈ 10.57° + 9.43° = 20.0°
ADC 中两束光的夹角 12.8°（其中一支向下 7.09°、另一支向上 5.67°）；从 DC 面射出后夹角扩大到约 20.0°。两束光的振动方向互相垂直（一支 ⊥ 纸面，一支在纸面内）。
验算小技巧：由疏到密那支（ne→n0）折射角 39.33° < 45°，靠向法线；由密到疏那支 52.09° > 45°，远离法线 —— 所以两支出射后一定分向两侧，夹角 = 两偏角之和，不是之差。

D · 波片1 题

波片题的坑在"对谁而言是几号波片"：同一块片子，对不同波长 δ 不一样（色散）。
2019-二-4λ1 的 1/4 波片对 λ2 是什么波片
已知方解石对波长 λ1 = 405 nm 光波的主折射率为 no = 1.6813，ne = 1.4969；对波长 λ2 = 710 nm 光波的主折射率为 no′ = 1.6521，ne′ = 1.4836。若一束波长为 λ2 的左旋正椭圆偏振光入射到相应于波长为 λ1 的方解石 1/4 波片上，求：（1）λ1 光波通过该波片时，所产生的相位差？（2）对于 λ2 光波而言，判断该波片是哪种波片？（3）出射光束的偏振态？

（1）

1定义就是答案：既然它是"对 λ1 的 1/4 波片"，则 λ1 通过时的相位差
δ1 = 2πλ1(no − ne)d = π2 = 90°，　且 (1.6813 − 1.4969)d = 4054 nm = 101.25 nm
⇒ d = 101.25 nm0.1844 = 549.1 nm

（2）

2同一块片对 λ2：
δ2 = 2πλ2(no′ − ne′)d = 2π710×10−9 × 0.1685 × 549.1×10−9 = 2π × 0.1303 = 0.819 rad = 46.9°

也可用比例一步算：δ2/δ1 = Δn′Δn · λ1λ2 = (0.1685/0.1844)(405/710) = 0.521 ⇒ δ2 = 0.521 × 90° = 46.9°。

3判据：46.9° 既不是 90°（1/4 波片）也不是 180°（1/2 波片）、更不是 360°。对 λ2 而言它只是一块"任意波片"，光程差 0.13λ（相当于约 1/8 波片，介于 1/8 与 1/4 之间）。

（3）

4入射是"正椭圆"（椭圆主轴恰在 o、e 振动方向上），经这块片子再叠加 46.9° 相位差后：椭圆主轴相对入射方向转过一个角度、椭圆率改变，但总的相位差仍在 0°～180° 区间内，旋向不翻转，仍是左旋。
（1）δ1 = 90°（d = 549.1 nm）；（2）对 λ2 它不是 1/4 波片，只是一块 δ ≈ 46.9° 的任意波片（光程差 0.13λ）；（3）出射仍为左旋椭圆偏振光，只是椭圆主轴方位与轴比发生变化。【待核】题面没有给入射"正椭圆"的轴比，所以第（3）问只能定性：主轴转角与轴比的具体数值取决于入射椭圆度；若把"正椭圆"理解为圆偏振（轴比 1），则出射为总相位差 90°+47° = 137° 的椭圆、长轴与 x 轴成 45°，轴比（短/长）= |tan(137°/2)|−1 ≈ 0.39。

2011-10给入射方向与界面法线，求反射、折射光线的方向矢量
沿 A0 = i 方向的光线，从 n = 1 的介质入射到 n′ = √3 的介质中，已知界面的法线方向为 n0 = −½i + (√3/2)j，求反射和折射光线的方向矢量。
1入射角：cos θ1 = |A0·n0| = |−½| = 0.5 ⇒ θ1 = 60°
2反射定律（矢量式）：A′ = A0 − 2(A0·n0)n0，代入 A0·n0 = −½
A′ = i + (−½i + √3/2j) = ½i + (√3/2)j

|A′| = √(¼ + ¾) = 1 ✓，且与 A0 关于界面（垂直于 n0）对称。

3折射定律：n sin θ1 = n′ sin θ2
1 × √32 = √3 · sin θ2 ⇒ sin θ2 = ½ ⇒ θ2 = 30°
4在入射面（xoy 面）内取与界面平行的单位矢量 t = (√3/2)i + ½j（t⊥n0，切向分量方向），令指向介质 2 的法线为 −n0，则
A″ = cos30°·(−n0) + sin30°·t = (0.433,−0.750) + (0.433,0.250)
A″ = (√3/2)i − ½j（|A″| = 1 ✓）
反射光线方向 ½i + (√3/2)j；折射光线方向 (√3/2)i − ½j（θ1 = 60°，θ2 = 30°，全在 xoy 面内）。
自检：两矢量都是单位矢量；折射光线与 −n0 的夹角 = 30° = θ2 ✓；切向分量之比 = sin60°/sin30°... 应比较 n·sinθ：1×sin60° = √3/2 = √3×sin30° ✓。

2011-11双平面镜：入射平行一镜、出射平行另一镜，求夹角
有一双平面镜系统，光线与其中的一个镜面平行入射，经两次反射后，出射光线与另一镜面平行，问两平面镜的夹角为多少。
1双平面镜的基本结论：入射光线经两镜依次反射后，偏向角 δ = 2α（α 为两镜夹角，取主截面内计算），且 δ 与入射角无关。
2题设"入射光线 ∥ 镜 1、出射光线 ∥ 镜 2"。出射方向相对入射方向转过的角度，正是两镜方向之间的夹角 —— 但它是 180° − α（出射光被"折回"到另一侧），不是 α。
δ = 2α = 180° − α
3解出
3α = 180° ⇒ α = 60°
4验算（α = 60°，镜 1 取 x 轴、镜 2 与它成 60°）：入射 (1,0) 先在镜 2 上反射得 (cos120°, sin120°)，再在镜 1 上反射得 (cos120°, −sin120°) ∝ −(½, √3/2)，恰与镜 2 的方向 (½, √3/2) 平行 ✓
两平面镜夹角 α = 60°（此时偏向角 δ = 120°，出射光与入射光反向偏折 120°）。
易错：直接写"δ = 2α 且 δ = α ⇒ α = 0"是漏了方向。α = 0 是两镜重合的退化情形，不算解；本题按"光线先被与它成 α 的那面镜反射"取几何，唯一非退化解是 60°。

2014-6石英涅拉斯顿棱镜（α=30°）：两束夹角；换成 n=no 玻璃后
如图所示为顶角 α = 30° 的两块石英晶体直角三棱镜组成的晶体偏振棱镜，光轴方向如图中所示，自然光垂直入射该棱镜，石英对 o 光和 e 光的折射率分别为 no = 1.544，ne = 1.553，试
（1）画出光在棱镜内和出射棱镜后光的传播方向，并标示出光矢量的振动方向；
（2）求棱镜 ADC 内两光束的夹角；
（3）若棱镜 ABC 被换成一个玻璃直角棱镜，该玻璃棱镜的折射率 n = no，画出光在棱镜内和出射棱镜后光的传播方向，并标示出光矢量的振动方向。
1结构（文字图）：ABC 与 ADC 两块直角三棱镜沿 AC 面胶合，顶角 α = 30°（B、D 为直角）。棱镜 ABC 的光轴平行于 AB（即平行于通光面），ADC 的光轴垂直于 ABC 的光轴。自然光正入射 AB 面时两支光同方向传播但折射率不同：一支在 ABC 中是 o 光（1.544）、另一支是 e 光（1.553）
2在胶合面 AC 上（对法线的入射角 = α = 30°）两支光互换角色并折射（斯涅尔定律）
o→e：nosin30° = nesinβ ⇒ sinβ = 1.544×0.51.553 = 0.4971 ⇒ β = 29.80°，偏 0.20°（向法线）
e→o：nesin30° = nosinβ′ ⇒ sinβ′ = 1.553×0.51.544 = 0.5029 ⇒ β′ = 30.19°，偏 0.19°（离法线）
3（2）ADC 内两光束夹角 = 两次偏折之和
γ = (30° − 29.80°) + (30.19° − 30°) ≈ 0.39° ≈ 23′

出射 DC 面后（空气）偏角按斯涅尔定律再放大 no,e 倍，约 0.58°；振动方向：两束都是线偏振，振动互相垂直且分别 ⊥ 与 ∥ 于纸面。

4（3）ABC 换成 n = no = 1.544 的玻璃：在 ABC 内是各向同性介质，两支光都以 no 传播、不分开；进入 ADC 后，振动 ∥ 光轴的一支变 o 光（no，与原折射率相同 ⇒ 不偏折），另一支变 e 光（ne）
1.544 sin30° = 1.553 sinβ ⇒ β = 29.80° ⇒ 只有这一支出射后偏 0.20°
（2）ADC 内两光束夹角 ≈0.39°（23′）；（3）换成 n = no 的玻璃后，o 光不偏折直出，e 光在胶合面上偏折 0.20°（出射到空气后约 0.31°）—— 棱镜仍把两束分开，但只有一束被偏折，分束角减半。
为什么角这么小：石英的 Δn = 0.009 很小（方解石的 Δn ≈ 0.17，同样的 Wollaston 能给出 ~20° 的分束角）。这也是石英 Wollaston 只用于需要小分束角、高精度的场合的原因。

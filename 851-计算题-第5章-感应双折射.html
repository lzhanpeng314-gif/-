这几道题考的是同一套东西：加电压 → 折射率椭球变形 → 两模产生相位差 δ → 检偏后变成强度变化。把 δ 和 V 的关系写对，剩下全是代数字。
相位差（纵向，KDP）
δ = 2πλ no3γ63V
纵向运用 E = V/l，而光程也 ∝ l，长度相消 ⇒ 与晶体尺寸无关。
半波电压（纵向）
Vλ/2 = λ2no3γ63
δ = π 所需电压。KDP 的 γ₆₃ 越小、n 越小，V 越大。
透过率（正交起检偏）
I = I0 sin2δ2 = I0 sin2πV2Vλ/2
起偏方向与感应主轴成 45° 才有调制；平行检偏则换成 cos²。
横向运用（LiNbO₃ 类）
δ = 2πλ no3γldV
E = V/d，光程长 l ⇒ 靠 l/d 换低电压；代价是电压与尺寸挂钩。

A · 纵向电光效应（KDP）1 题

纵向 KDP 的标准套路：写 δ(V) → 令 δ = π 得半波电压 → 用 I = I₀sin²(δ/2) 求两种电压下的输出。
2017-二-5KDP 纵向运用：半波电压，以及 V = 0 与 V = Vλ/2 时的输出光强
如图所示，为纵向运用的电光晶体 KDP（no = 1.512，γ63 = 10.6×10−10 cm/V），P 为偏振器，入射的线偏振光波长 λ = 550 nm。
（1）试求出 KDP 晶体的半波电压 Vλ/2；
（2）求出电源电压 V = 0 和 V = Vλ/2 时的输出光强，并绘出光路。

（1）

1纵向运用：电场沿光轴 z，光也沿 z 传播。加电压后折射率椭球变形，感应主轴 x′、y′ 相对原主轴转过 45°，两模的折射率差
Δn = no3γ63E，　E = Vl
2相位差 = 光程差 × 2π/λ，注意 l 会消掉（这正是"纵向"的好处）
δ = 2πλ Δn · l = 2πλ no3γ63V
3令 δ = π 得半波电压
Vλ/2 = λ2no3γ63
4代入数值：no3 = 1.512³ = 3.4566，γ63 = 10.6×10−10 cm/V = 1.06×10−11 m/V
Vλ/2 = 550×10−92 × 3.4566 × 1.06×10−11 = 550×10−97.328×10−11
Vλ/2 ≈ 7.5×103 V = 7.5 kV

（2）

5光路：入射的线偏振光振动方向沿 x（与晶体的一个主轴平行），P 的透光轴沿 y，两者正交。晶体把入射振动按 45° 分解到感应主轴 x′、y′ 上，出射后相位差为 δ，再经 P 取 y 分量
I = I0 sin2δ2 = I0 sin2πV2Vλ/2
6V = 0 ⇒ δ = 0：晶体不产生附加相位差，出射仍是沿 x 的线偏振，被 P 全部挡掉
I = I0 sin20 = 0
7V = Vλ/2 ⇒ δ = π：相当于一块半波片，且入射振动与波片主轴成 45°，出射振动转过 90°（x → y），正好全部通过 P
I = I0 sin2π2 = I0
8光路图（文字版）：
V = 0：I₀（沿 x 线偏振）→ KDP（无相位差）→ 仍沿 x → P（透光轴 y）→ 0；
V = Vλ/2：I₀（沿 x）→ KDP（δ = π）→ 沿 y → P（透光轴 y）→ I₀。
半波电压 Vλ/2 ≈ 7.5 kV；V = 0 时输出光强为 0，V = Vλ/2 时为 I₀（出射振动由 x 转到 y，从"全挡"变成"全通"）。
约定说明：题面只写了"P 为偏振器"、没写入射光的振动方向。这里按图取"入射振动沿 x、P 透光轴沿 y（正交）"，此时 I = I₀sin²(δ/2)。若你的图上 P 与入射振动平行，则换成 I = I₀cos²(δ/2)，答案变为 I₀ 与 0 —— 两种写法只是起检偏的相对方位不同。

B · 电光强度调制（LiNbO₃）1 题

这道题的关键不在算术，而在判断是纵向还是横向：题面没给晶体尺寸，只有横向公式里含 l/d，所以必须按"l = d"（纵向、电压与尺寸无关）才能算出数来。
2024-二-6LiNbO₃ 产生 π/2 相位延迟所需电压；起偏器该放多少度
LiNbO₃ 晶体在 λ = 550 nm 时，no = 2.29，电光系数 γ = 3.4×10−5 m/V，光沿 x 方向传播。
（1）为使该晶体产生 π/2 的相位延迟，外加电压应为多少？
（2）若此装置用于电光强度调制，晶体前起偏器的偏振化方向与 x 轴成什么角度？为什么？

（1）

1按图：光沿 x₃ 传播、电场沿 x₂ 加在厚度 d 上，是横向运用；x₃ 是光轴，所以两个模的自然折射率都是 no，相位差完全由电场产生
δ = 2πλ no3γ ld V
2令 δ = π/2
V = λ4no3γ · dl

题面未给 l、d，只能取 l = d（纵向极限，电压与尺寸无关）才能得到唯一数值。

3数值：no3 = 2.29³ = 12.009；γ 取 3.4×10−12 m/V（理由见【待核】）
V = 550×10−94 × 12.009 × 3.4×10−12 = 550×10−91.633×10−10 ≈ 3.4×103 V

若为横向且 l/d = 2，则电压减半：V ≈ 1.7 kV。

（2）

4加电场后 x₁、x₂ 就是两个感应主轴（x₃ 为光轴，光沿它传播时只有横向的两个振动模），两个模的相位差 δ 只在这两个方向上分配振幅。
5起偏器应与 x 轴（x₁）成 45°：这样入射振动在 x₁、x₂ 上分成振幅相等的两束，出射后再由检偏器取分量，强度才随 δ 按 sin²(δ/2) 变化，调制深度最大。
I = I0 sin2δ2，　δ = kV
6反例说明"为什么必须 45°"：若偏振沿 x₁（0°）或 x₂（90°），光在晶体中只激发一个模式，出射偏振态不随电压变化，检偏器输出恒定 ⇒ 只有相位调制，没有强度调制。
（1）外加电压约 3.4 kV（取 l = d；横向时与 d/l 成正比）；（2）起偏器偏振化方向与 x 轴成 45°，使两个感应主轴方向振幅相等，才能获得最大调制深度。
【待核】题面印的是 γ = 3.4×10−5 m/V，比 LiNbO₃ 实际值（r₂₂ ≈ 3.4 pm/V = 3.4×10−12 m/V）大 7 个数量级；若照题面数字算得 V ≈ 3.4×10−4 V，显然不合理，故按 3.4×10−12 m/V 计算。另外题面"光沿 x 方向传播"应为图中 x₃，且缺 l/d 数值 —— 这两点需要核对原卷。

C · KDP 半波电压与圆偏振条件1 题

2020-二-5产生 π/2 相位延迟要加多少伏；怎样才能出圆偏振
图示 A 为纵向运用的电光晶体 KDP，在波长 λ = 0.55 μm 时，n0 = 1.51，ne = 1.512，γ63 = 10.6×10−12 cm/V。为使该晶体产生 π2 的相位延迟，外加电压应为多少；在此电压条件下，一束水平偏振的线偏振光入射晶体，出射光的偏振状如何？在什么条件下能输出圆偏振光？
1纵向运用：电场与光同沿 x3，E = U/l，两支光走同一长度 l，故
δ = 2πλ(n1′ − n2′)l = 2πλn03γ63U

单位统一：γ63 = 10.6×10−12 cm/V = 1.06×10−11 m/V（题面指数为笔误，见文末 warn）。

2令 δ = π/2 反解电压。因为 δ = 2πU/Uπ，π/2 对应 Uπ/2：
U = λ4n03γ63 = 0.55×10−64 × 1.513 × 1.06×10−11 = 5.5×10−71.4598×10−10 = 3.77×103 V
3出射偏振：水平偏振沿晶体自然主轴 x1，而感应主轴 x1′、x2′ 与它成 45°，所以两支等幅；相位差恰为 90° ⇒ 圆偏振光。
4推广到"什么条件出圆偏振"：等幅（振动与感应主轴成 45°）+ 相位差为 π/2 的奇数倍
U = (2k + 1)Uπ2 = (2k + 1) × 3.77 kV（k = 0, 1, 2…）
所需电压 U = 3.77 kV（即 Uπ/2，Uπ ≈ 7.5 kV）；该电压下水平偏振入射，出射为圆偏振光；一般条件是：入射振动与感应主轴成 45°，且 U = (2k+1)×3.77 kV（旋向随 k 奇偶交替）。
题面两处要注意：① γ63 的"10−12 cm/V"应为 10−12 m/V（=10−10 cm/V）；照字面按 cm/V 算，Uπ 会大 100 倍（≈754 kV），明显不合理。② 题给的 n0 = 1.51、ne = 1.512 是晶体自然主折射率，纵向运用中光沿光轴走，自然双折射不起作用，只由 γ63 产生感应相位差。

D · KDP + 方解石：间距与相位差1 题

这题的骨架：KDP 当开关把偏振转 90°，方解石当"分束器"把 o、e 光掰开。算间距只要一个走离角。
2022-三-6半波电压；B 晶体输出的两光间距与相位差
图中 A 为纵向运用的电光晶体 KDP（n0 = 1.512，γ63 = 10.6×10−10 cm/V），B 为厚度 d = 10 mm 的方解石晶体（n0 = 1.5246，ne = 1.4792，光轴方向与通光面的法线方向成 45° 夹角），A、B 晶体平行放置，试计算一束波长为 550 nm 的线偏振光（光电场振动方向沿晶体光轴方向）垂直入射 KDP 时，晶体的半波长为多大？绘出相应的电压 U = Uλ/2 时 A、B 晶体的传输光路图及振动方向，并计算由 B 晶体输出的两光间距、相位差。

（1）半波电压

1γ63 = 10.6×10−10 cm/V = 1.06×10−11 m/V，n03 = 1.5123 = 3.4567
Uλ/2 = λ2n03γ63 = 550×10−92 × 3.4567 × 1.06×10−11 = 5.5×10−77.328×10−11 = 7.50×103 V

（2）U = Uλ/2 时的光路与振动方向

2A（KDP）在 U = Uλ/2 时相当于半波片：入射振动沿一个主轴（题面"沿晶体光轴方向"按"沿 KDP 主轴 x1"理解 —— 纵向运用时 E 不可能沿光轴），出射仍为线偏振，但振动方向转过 90°（转成沿 x2）。光路在 A 内是直线（纵向，无偏折）。
3B（方解石）：光垂直入射，波法线沿法线、与光轴成 θ = 45°。o 光沿法线直进；e 光的光线偏离法线，偏角就是走离角
tanρ = sin45°cos45°(ne2 − n02)n02sin245° + ne2cos245° = 0.5 × (2.1880 − 2.3244)0.5 × (2.3244 + 2.1880) = −0.0302
|ρ| = 1.73°（e 光偏向光轴一侧）

（3）间距

4
s = d tanρ = 10 mm × 0.0302 = 0.30 mm

两光从 B 的第二个面射出时都平行于原入射方向（平行平板），所以这 0.30 mm 就是它们之间固定的间距。

（4）相位差

5两支光波法线相同（都沿法线），相位差取"法线方向的等效折射率"：θ = 45° 时
1ne2(45°) = cos245°1.52462 + sin245°1.47922 ⇒ ne(45°) = 1.5014
δ = 2πλ(ne(45°) − n0)d = 2π550×10−9 × (−0.0232) × 0.01 = −2.65×103 rad
折合 |δ|2π = 422 个波长 ⇒ o 光超前，两光实际上是同相的（小数部分 0.08，即 29°）
（1）Uλ/2 ≈ 7.5 kV；（2）A 起 1/2 波片作用、把振动方向转 90°，B 内 o 光直进、e 光偏 1.73°；（3）B 输出两光间距 0.30 mm；（4）相位差 |δ| ≈ 2.65×103 rad（约 422 个波长）。【待核】相位差这一步的口径：若忽略光轴的 45° 倾角、直接用主折射率 ne，则得 2π(0.0454)(0.01)/5.5×10−7 ≈ 5.2×103 rad（825 个波长）。本页取有效折射率（物理上正确）的 422 个波长。

双缝条纹间距
Δx = λDd
波长 × 屏距 ÷ 缝距。屏越远、缝越密，条纹越宽。
相干长度
Lc = λ2Δλ
波长的平方 ÷ 谱线宽度。谱线越窄，能相干的距离越长。
斜入射等厚干涉极大
2nd cosθ = kλ
斜着看，光程差要乘 cos θ —— 最容易漏的一项。
λ/4 膜反射率
R = n0ng − nf2n0ng + nf22
nf 膜、ng 玻璃、n0 空气；nf=√ng 时 R=0。
本章大点 · 干涉题的三步骨架
  • ① 找光程差 Δ（把两束光各自的路程折算到同一介质里，别漏半波损失）
    ② 套条件：Δ = kλ 亮，Δ = (k+½)λ 暗
    ③ 要条纹：间距 = 2π 相位对应一个 Δ 变化；要可见度：看两个“不相等”
  • 可见度 V = (Imax−Imin)/(Imax+Imin)，三种掉可见度的原因：
原因判据
两束光强不等V = 2√(I₁I₂)/(I₁+I₂)
光源有宽度（空间相干）光源宽度 < λR/d 才看得见条纹
谱线有宽度（时间相干）光程差 < 相干长度 Lc = λ²/Δλ
  • 易错：可见度下降 ≠ 条纹消失；判断“还能不能看到”要用相干长度或光源宽度条件。

A · 杨氏双缝
  • 条纹间距 ∝ λ，∝ 距离 D，反比于缝距 d
  • 插介质片 (n−1)t 使条纹整体平移
Δx = λDd

四道题考的是同一个骨架：条纹间距 → 光程差/移动 → 相干长度/可见度。参数换来换去而已。
2016-二-1由 10 个条纹间距反求波长；白光时条纹如何变
在双缝干涉实验中，缝间距为 0.5 mm，观察屏距离缝 1.2 m，现用读数显微镜测得 10 个干涉条纹（准确说是 11 个亮条或暗条）之间的距离为 12 mm，试求所用光的波长。用白光实验时，干涉条纹有什么变化？
111 个亮条之间是 10 个间距
Δx = 12 mm / 10 = 1.2 mm
2
λ = Δx·d/D = 1.2×10−3 × 0.5×10−3 / 1.2 = 5.0×10−7 m
λ = 500 nm；白光时：中央（k=0）仍是白光，两侧形成彩色条纹，因 Δx ∝ λ 使红光条纹最宽、紫光最窄，高级次处各色重叠 → 只能看到少数几级彩色，再往外模糊成白色。

2017-二-2贴薄片后条纹移动距离；多厚才使条纹消失
S1、S2 小孔的间距为 0.5 mm，光屏离小孔的距离为 50 cm，当以厚度为 1.667×10−2 mm、折射率为 1.60 的透明薄片贴住小孔 S1 时，发现屏上的条纹有移动。
（1）试确定条纹移动的距离；（2）如果入射光的波长宽度为 0.04 nm、平均波长为 500 nm，则该透明薄片多厚可使观察屏上 P0 点附近的干涉条纹消失？

（1）

1薄片引入的附加光程
(n−1)t = 0.60 × 1.667×10−2 mm = 1.0×10−2 mm = 10 μm
2相当于条纹平移了多少级
N = (n−1)t / λ = 10×10−6 / 500×10−9 = 20 级
3条纹间距与移动距离
Δx = λD/d = 500×10−9×0.5 / 0.5×10−3 = 0.5 mm
Δy = N·Δx = 20 × 0.5 mm = 10 mm

方向：向 S1 一侧（向上）移动 —— 光程增加的那一侧，条纹朝它移。

（2）

4相干长度
Lc = λ2Δλ = (500 nm)20.04 nm = 6.25×10−3 m = 6.25 mm
5附加光程差 ≥ 相干长度时条纹消失
(n−1)t ≥ Lc　⇒　t ≥ 6.25/0.60 ≈ 10.4 mm

2021-二-1条纹间距、水中变化、消失级次、光源临界宽度四问综合
杨氏双缝实验中，双缝间距 d = 0.5 mm，接收屏距双缝 D = 1 m，点光源距双缝 l = 30 cm，点光源发射波长为 500 nm 的单色光，试求：
（1）屏上的条纹间距，若把整个装置放入水中，条纹间距如何变化；
（2）若点光源发出的光波长为（500 ± 2.5）nm 范围内的准单色光，求接收屏上干涉条纹消失时的级次；
（3）若光源具有一定的宽度，屏上干涉条纹消失时，它的临界宽度是多少？
1（1）空气中
Δx = λDd = 500×10−9×10.5×10−3 = 1 mm
2入水后波长变短 λ′ = λ/n（n ≈ 1.33）
Δx′ = Δx/n ≈ 1/1.33 ≈ 0.75 mm　（条纹变密）
3（2）波列长度有限，级次太高则两束不再相干。判据：kΔλ ≥ λ/2
kmax = λ/(2Δλ) = 500/(2×5) = 50 级

Δλ = 2.5×2 = 5 nm（"±2.5"是半宽，全宽为 5 nm）。第 50 级以后条纹消失。

4（3）光源宽度使两侧边缘的条纹错开半个间距
b·d/l = λ/2　⇒　b = λl/(2d) = 500×10−9×0.30 / (2×0.5×10−3) = 0.15 mm
Δx = 1 mm；水中 0.75 mm；条纹消失级次 ≈ 50 级；光源临界宽度 ≈ 0.15 mm。

B · 两束平面波
  • 夹角 2α，条纹垂直平分面
  • α 越小条纹越疏
d = λ2sinα
这一类只考"波矢差 → 条纹间距"，一个公式通吃：Δx = 2π/|Δkx|。
2022-三-2两平面波分居 z 轴两侧，z 平面上条纹形状与间距同 2010-1
如图所示，两相干平面光波，其一在 xz 平面沿与 z 轴夹角 θ1 方向传播，其二在 xz 平面沿与 z 轴夹角 θ2 方向传播，试求该二光波在 z 平面上的干涉条纹形状和条纹间距。
图 · 点此收起 / 展开
1两波矢（分居 z 轴两侧时 x 分量反号）
k1 = k(sin θ1, 0, cos θ1)，　k2 = k(−sin θ2, 0, cos θ2)
2在 z = 0 平面上相位差只随 x 变
Δφ = (k1x − k2x)·x = k(sin θ1 + sin θ2)·x
3条纹间距
Δx = 2π|Δkx| = λsinθ1 + sinθ2
形状：一组平行于 y 轴（垂直于 xz 平面）的等间距直条纹；
间距：Δx = λ/(sin θ1 + sin θ2)（两波在 z 轴同侧时改为 λ/|sin θ1 − sin θ2|）。

2024-二-3两相互垂直的光波，z = 0 平面上的条纹
如图所示，两相互垂直光波在 xz 平面传播，其一在 xz 平面沿与 z 轴夹角 θ1 方向传播，其二在 xz 平面沿与 z 轴夹角 θ2 方向传播，求该二光波在 z = 0 平面上的干涉条纹形状和条纹间距。
图 · 点此收起 / 展开
1先分清"垂直"指什么 —— 这是本题的陷阱，两种理解答案完全不同：
2情形一：两波振动方向相互垂直（正交偏振） —— 不满足干涉条件（振动方向必须不垂直）。
I = I1 + I2　（无干涉项）

此时屏上没有条纹，光强均匀分布。这是 851 常考的概念陷阱。

3情形二：两波振动方向平行（都垂直于 xz 面，即 s 偏振）—— 正常干涉
Δx = λ / (sin θ1 + sin θ2)

条纹为平行于 y 轴的直条纹，与上一题同形。

答题建议：先写"振动方向垂直 ⇒ 不产生干涉条纹，I = I1+I2，屏上均匀照明"，再补一句"若两波振动方向平行，则条纹间距为 λ/(sinθ1+sinθ2)"。两手都写，稳拿分。

C · 劈尖等厚干涉1 题

C · 劈尖
  • 两纹间厚度差 λ/2n
  • 空气劈尖下表面有半波损失
2nh + λ2 = kλ
l = λ2nθ
空气劈尖只有下表面是从玻璃到空气（有半波损失），上表面没有，所以整个光程差里只加一次 λ/2。
2018-二-2斜入射劈尖的条纹数；换成空气劈尖后是多少
如图所示的劈尖薄膜，右端厚度 h 为 0.05 mm，折射率为 1.5，波长为 707 nm 的光以 30° 角入射到上表面，求在这个面上产生的条纹数。若以两块玻璃片形成的空气尖劈代替，将产生多少个条纹？
图 · 点此收起 / 展开
1膜内折射角（空气 → 膜）
sin θt = sin30°/1.5 = 1/3　⇒　θt = 19.47°，cos θt = 0.9428
2斜入射的光程差是 2n t cos θt（不是 2nt！）
Δ = 2n h cosθt + λ2
3条纹数 = 最大光程差对应的级数
N = 2n h cosθtλ = 2×1.5×0.05×10−3×0.9428707×10−9 ≈ 200 条
4换成空气劈尖（n = 1，同 30° 入射，cos θt = cos30° = 0.866）
N′ = 2 h cos30° / λ = 2×0.05×10−3×0.866 / 707×10−9 ≈ 122 条
玻璃膜劈尖 200 条；空气劈尖约 122 条（若按正入射则 N′ = 2h/λ ≈ 141 条）。
易错：① 斜入射忘了 cos θt；② 把 θ = 30° 直接当膜内角；③ 空气劈尖若也按 30° 斜入射，是 122 条而不是 141 条 —— 取决于题目是否保持同一入射角，两种都写更稳。

D · F-P 干涉仪与干涉滤光片2 题

D · F-P 与滤光片
  • 多光束干涉，峰极锐
  • 斜入射中心波长向短波移
2nhcosθ′ = kλ
R = k·Neff
2019-二-2由条纹错位求波长差；求分辨本领
某光源发出波长很接近的两单色光，平均波长为 600 nm，通过间隔 d = 10 mm、腔镜反射率为 0.98 的法布里–珀罗干涉仪观察时，看到波长为 λ1 的光所产生的干涉条纹正好在波长为 λ2 的光所产生干涉条纹的中间，试求：两单色光的波长差；在接近正入射时，此干涉仪的分辨本领？（取平均波长为 600 nm）
1正入射时 2d = kλ，级次
k = 2d/λ = 2×10×10−3 / 600×10−9 ≈ 3.33×104
2"λ1 的条纹在 λ2 两条纹中间" ⇒ 两波长对应的级次差 1/2
k·Δλ = λ2　⇒　Δλ = λ2k = 600 nm2×3.33×104 ≈ 0.009 nm
3分辨本领 = 级次 × 精细度 F
F = π√R1 − R = π√0.981 − 0.98 ≈ 155.5
Rp = k·F ≈ 3.33×104 × 155.5 ≈ 5.2×106
波长差 Δλ ≈ 0.009 nm；分辨本领 ≈ 5.2×106（相当于能分辨 1.2×10−4 nm）。

2020-二-2干涉滤光片的中心波长、半宽度、斜入射透射波长
今有一干涉滤光片，其间隔层厚度为 2×10−4 mm，折射率 n = 1.5，高反膜的反射率 R = 0.9，试求：光波垂直入射，滤光片在可见光区的中心波长及其透射带波长半宽度；当光波以 10° 角斜入射时，滤光片在可见光区的透射光波长。
1正入射中心波长（取 k = 1 落在可见区）
2nd = 2×1.5×2×10−4 mm = 6×10−4 mm = 600 nm　⇒　λ0 = 600 nm

E · 光学薄膜1 题

E · 光学薄膜
  • λ/4 膜：增透取 n=√(ng)，增反交替高低折射率
R = (n0−n)2(n0+n)2
斜入射用 ndcosθ 代替 nd
2021-二-3氟化镁增透膜的厚度、最小反射率、与未镀膜比较
在折射率 n = 1.6 的光学玻璃基底上镀氟化镁膜层 n = 1.38，要求对波长为 500 nm 的光在正入射时给出最小反射率，试求：镀膜材料氟化镁膜层厚度及相应的最小反射率；与没有镀膜时的反射率相比较，变化了多少？
1λ/4 膜厚
d = λ/(4nf) = 500/(4×1.38) ≈ 90.6 nm
2λ/4 膜正入射反射率公式
R = n0ng − nf2n0ng + nf22 = 1×1.6 − 1.3821×1.6 + 1.3822 = −0.30443.50442 ≈ 0.75%
3未镀膜时
R0 = [(ng−n0)/(ng+n0)]² = (0.6/2.6)² ≈ 5.33%
膜厚 90.6 nm；最小反射率 0.75%；未镀膜 5.33% → 降低约 4.6 个百分点（相对下降 86%）。
本题的"坑"：理想增透要求 nf = √ng = √1.6 = 1.265，而氟化镁是 1.38，不满足 —— 所以反射率只能降到 0.75%，不能降到 0。答题时要写这句判断，比只算数值加分。

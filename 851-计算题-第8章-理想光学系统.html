这一章只有两条路：① 给"总焦距 f′ / 总长 L / 后截距 l′F"中的几个，反求 f1′、f2′、d —— 三个方程解三个未知数； ② 物像关系题，β = l′/l 与高斯公式联立，一律"分段成像"：先第二组反推第一组，或从物方逐面推过去。 另外两条换算别记反：总长 L = d + 后截距；f = −f′（空气中）。
双光组组合焦距
1f′ = 1f1′ + 1f2′ − df1′f2′
等价式 f′ = f1′f2′/(f1′+f2′−d)。分母可正可负 ⇒ f′ 可以为负。
后截距（像方焦点位置）
l′F = f′1 − df1′
从第二组量起。d > f1′ 时为负 ⇒ 焦点跑到第二组左侧（长焦/反远距结构）。
高斯公式（符号法则）
1l′ − 1l = 1f′　　β = l′l
光线从左来、l 向左为负。β < 0 倒立，β > 0 正立。
总长与主面
L = d + l′F　　l′H = l′F − f′
"总长"一律指第一组到像方焦点的距离，不是间隔 d。四个题都在这条上设过坑。

A · 双光组组合4 题

四道题的已知量组合各不相同，但都能从上面三条式里挑两条解出。先定 d，再用后截距定 f1′，最后用组合焦距定 f2′。
2022-三-5双光组：已知像距与像高，反求物面位置与物高
一个光学系统由两个薄透镜构成，两个薄透镜的焦距依次为 60mm 和 40mm，两者相距 150mm，已知一个物体成正立的实像，像位于第二个透镜后 168mm 处，像高为 5mm，试计算物体的位置和物高。

思路：像在最后，只能"从像方往回推"——先过第二透镜得到中间像，再过第一透镜得到物。

1对第二透镜：l2′ = 168 mm，f2′ = 40 mm
1l2 = 1168 − 140 = 40 − 168168 × 40 = −152.5　⇒　l2 = −52.5 mm
2即第一透镜所成的中间像在第二透镜前 52.5 mm，所以它对第一透镜的像距
l1′ = d + l2 = 150 − 52.5 = 97.5 mm
3第二透镜的放大率
β2 = l2′l2 = 168−52.5 = −3.2
4对第一透镜：l1′ = 97.5 mm，f1′ = 60 mm
1l1 = 197.5 − 160 = 0.01026 − 0.01667 = −0.00641 = −1156　⇒　l1 = −156 mm
5β1 = 97.5/(−156) = −0.625，于是
β = β1β2 = (−0.625)(−3.2) = +2.0 > 0 ✓（题设"正立"）
6物高
y = y′β = 52 = 2.5 mm
物在透镜 1 前 156 mm（l1 = −156 mm），物高 2.5 mm；中间像在透镜 1 后 97.5 mm、透镜 2 前 52.5 mm，系统放大率 +2。

2017-四-2短焦距照相物镜：由 f′、工作距离、总长反求两片焦距
一个由两个薄透镜构成的短焦距照相物镜，已知焦距 f′ = 28mm，工作距离 l′ = 40mm，总长度（第一透镜到物镜像方焦点的距离）L = 55mm，试求这两个薄透镜的焦距 f1′ 和 f2′ 及其它们的间距 d。
1"工作距离"就是后截距 l′F（最后一片到像方焦点）。总长 = 间隔 + 后截距：
d = L − l′F = 55 − 40 = 15 mm
2代入后截距公式
40 = 281 − 15f1′　⇒　1 − 15f1′ = 107　⇒　15f1′ = −37　⇒　f1′ = −35 mm

负值说明第一片是负透镜：后截距 40 mm 比焦距 28 mm 还长，只有"负–正"结构才做得到。

3再用组合焦距式求 f2′
28 = (−35)f2′−35 + f2′ − 15 = −35f2′f2′ − 50
28f2′ − 1400 = −35f2′　⇒　63f2′ = 1400　⇒　f2′ = 22.2 mm
4验算
1f′ = −135 + 122.22 − 15(−35)(22.22) = −0.02857 + 0.04500 + 0.01929 = 0.03571 ✓
f1′ = −35 mm（负透镜在前）、f2′ ≈ 22.2 mm、d = 15 mm。属反远距（retrofocus）型：工作距离 40 mm > f′ = 28 mm。
易错：总长 L = d + 后截距，直接令 d = 55 会连锁错到底。另外 f1′ 解出负值时不要慌，这正是"短焦 + 长后截距"的必然结果。

2018-四-1已知 f′、总长、后截距，反求双光组
已知双光组组合，合成光组焦距为 f′ = 1000mm，总长（第一光组到系统像方焦点的距离）L = 700mm，总焦点 l′F = 400mm，求组成该系统的双光组焦距及其间隔。
1间隔
d = L − l′F = 700 − 400 = 300 mm
2后截距定 f1′
400 = 10001 − 300f1′　⇒　1 − 300f1′ = 0.4　⇒　f1′ = 500 mm
3组合焦距定 f2′
1000 = 500f2′500 + f2′ − 300　⇒　1000(200 + f2′) = 500f2′
200000 + 1000f2′ = 500f2′　⇒　500f2′ = −200000　⇒　f2′ = −400 mm
4验算
1f′ = 1500 − 1400 + 300500 × 400 = 0.002 − 0.0025 + 0.0015 = 0.001 ✓（f′ = 1000）
f1′ = 500 mm、f2′ = −400 mm、d = 300 mm。后组为负 ⇒ 主面被"拉"到系统外面，属望远型（telephoto）结构。

2020-四-2已知间隔、放大率、共轭距，反求两光组焦距
已知两个薄透镜光组组合，两个薄透镜的主点之间的间隔 d = 50mm，β = −5，共轭距为 L = 150mm，物距 l1 = −35mm，求两个光组的焦距。
1共轭距 = 物面到像面，按图拆成三段
L = |l1| + d + l2′　⇒　l2′ = 150 − 35 − 50 = 65 mm
2放大率用两段串起来：β = (l1′/l1)(l2′/l2)，且 l2 = l1′ − d
−5 = l1′−35 · 65l1′ − 50
65l1′ = 175(l1′ − 50)　⇒　110l1′ = 8750　⇒　l1′ = 79.55 mm
3于是 l2 = 79.55 − 50 = 29.55 mm（对第二光组是虚物，落在它右侧）
4两个光组分别用高斯公式
1f1′ = 179.55 + 135 = 0.01257 + 0.02857 = 0.04114　⇒　f1′ = 24.3 mm
1f2′ = 165 − 129.55 = 0.01538 − 0.03385 = −0.01846　⇒　f2′ = −54.2 mm
5验算
β1 = 79.55−35 = −2.273，β2 = 6529.55 = +2.2，β = −5.0 ✓

组合焦距 f′ = 16.5 mm，物方主面在 H1 左侧 15.2 mm 处（所以题给的 l1 只能配 分段算法，不能直接套到整个系统上）。

f1′ ≈ 24.3 mm、f2′ ≈ −54.2 mm（组合 f′ ≈ 16.5 mm）。精确值：f1′ = 875/36 mm、f2′ = −325/6 mm。
口径提醒：本题"共轭距 150 mm"按图上标注（物面 ↔ 像面）取，所以 l2′ = 65 mm。若按"从 H1 量到像面 150 mm"理解，则 l2′ = 100 mm，解出 f1′ = 26.9 mm、f2′ = −200 mm。两种口径都自洽，答题时把定义写清楚。

B · 高斯公式与二次成像1 题

"二次成像测焦距"是实验题的计算版：同一系统两次成像，两次的 β 与两次的物像距差联立即可。
2021-四-2二次成像法：由两次像高反求 f′ 与物移动量
采用二次成像法可以测量光学系统的焦距。已知将一个高为 10cm 的物置于一个光学系统的前方，在光学系统的后方得到一高为 4.0cm 倒立的实像；当将物沿光轴向光学系统方向移动一段距离，像远离光学系统沿光轴移动了 10cm，像仍为倒立的实像、高变为 14.0cm，试
（1）确定该光学系统的像方焦距；
（2）物沿光轴移动的距离。
1第一次：记物距 −a、像距 b，像高 4.0 / 物高 10 ⇒ β1 = −0.4
β1 = b−a = −0.4　⇒　b = 0.4a
2第二次：像高 14.0 / 10 ⇒ β2 = −1.4；物向内移 Δ（物距 −(a−Δ)），像向外移 10 cm（像距 b+10）
−1.4 = b + 10−(a − Δ)　⇒　b + 10 = 1.4(a − Δ)
代入 b = 0.4a：　0.4a + 10 = 1.4a − 1.4Δ　⇒　a − Δ = 0.4a + 101.4
3两次都满足高斯公式，焦距不变，把两式写成同一形式
第一次：1a + 1b = 1a + 10.4a = 3.5a = 1f′
第二次：10.4a + 10 + 1.40.4a + 10 = 2.40.4a + 10 = 1f′
3.5a = 2.40.4a + 10　⇒　1.4a + 35 = 2.4a　⇒　a = 35 cm
4焦距与像距
f′ = a3.5 = 10 cm，　b = 0.4 × 35 = 14 cm
5物移动量
Δ = a − 0.4a + 101.4 = 35 − 241.4 = 35 − 17.14 = 17.86 cm

回代检查：l2 = −(35−17.86) = −17.14 cm，l2′ = 24 cm，1/24 + 1/17.14 = 0.0417 + 0.0583 = 0.1 ⇒ f′ = 10 cm ✓；β2 = 24/(−17.14) = −1.4 ✓。

（1）f′ = 10 cm（100 mm）；（2）物沿光轴移近 17.9 cm（35 cm → 17.1 cm，像距 14 cm → 24 cm）。

一 · 物理光学 简答题

2018-1(2)同为等倾，为何双光束看反射、多光束看透射
平行平板的双光束干涉和多光束干涉同为等倾干涉，为什么前者应用的常是反射光，而后者应用的通常是透射光？
5 分
  • 双光束 → 看反射光：平板反射率低时，反射光中两束（表面直接反射 + 一次内反射后出射）强度接近， 可见度 V = 2√(I1I2) / (I1+I2) → 1； 而透射光是 t2 与 t2r2 一强一弱，V 很低。
  • 多光束 → 看透射光：高反射率腔里透射的一串光强相近，叠加后条纹极细锐 （半宽随 R 增大而变窄，精细度 F = π√R / (1−R) 上升）； 反射光是它的互补——“亮背景上的细暗线”，对比差。所以取透射。

一句话：双光束拼的是两束强度是否相称（看可见度），多光束拼的是条纹够不够锐（看精细度）。

2019-1(4)沿光轴入射 / 光轴平行表面正入射，会不会双折射
两种入射情况：1）光波沿晶体的光轴入射；2）若光轴平行于晶体表面，光波正入射于晶体表面。问这两种情况下是否会发生双折射现象？请说明理由。
5 分

①沿光轴入射：不发生双折射。此时 o 光与 e 光传播方向相同、速度也相同（都等于 no），两束光不分开。

②光轴平行于表面、光垂直入射：发生双折射。此时光轴垂直于传播方向，o 光与 e 光速度不同（分别为 no、ne），产生双折射 —— 但因两者仍沿法线传播，传播方向相同，只是速度不同（不分开）。

同类问法见 2024-1(4)：ne 只在波法线⊥光轴时才叫 e 光折射率。

2019-1(5)由 dn/dλ 的符号判断色散类型
dn/dλ 表示介质折射率随波长改变的变化率，即为色散率。当色散率 dn/dλ < 0 和 dn/dλ > 0 时，相应介质的光色散类型是什么？
5 分
  • dn/dλ < 0：折射率随波长增大而减小，V > Vg → 正常色散；
  • dn/dλ > 0：折射率随波长增大而增大，V < Vg → 反常色散。

2021-1(5)KDP 线性电光效应，γ63 纵向与横向运用的条件
简述 KDP 晶体的线性电光效应，产生 γ63 的纵向运用和横向运用的条件。
5 分

KDP 加电场后由单轴晶体变为双轴晶体，折射率变化与场强成正比（普克尔斯效应），比例系数即 γ63。

  • 纵向运用：外加电场方向与光传播方向平行（都沿光轴 z），两端加透明电极；
  • 横向运用：电场方向与光传播方向垂直（如电场沿 z、光垂直光轴传播）。

纵向运用时半波电压与晶体长度无关；横向运用可增大长度/减小厚度来降低半波电压。

2019-二-3中央峰角宽度、可分辨的最小波长差
平面透射光栅每毫米内 400 条刻线，光栅宽为 5 cm。当波长为 500 nm 的平行光垂直入射到该光栅，发现第 4 级衍射光谱处在单缝衍射的第一极小位置，试求：衍射中央峰的角宽度；正入射时光栅能分辨的谱线最小波长差。
10 分
1光栅常数与缝宽：d = 1/400 mm = 2.5 μm；第 4 级主极大落在单缝第一极小处，故 d/a = 4
a = d/4 = 0.625 μm
2“衍射中央峰”指单缝衍射包络的中央明纹（不是干涉主极大！），宽度由缝宽决定，与刻线总数 N 无关
sinθ1 = λ/a = 0.5/0.625 = 0.8 ⇒ θ1 = 53.13°
中央峰全角宽 = 2θ1 = 106.3° ≈ 1.86 rad

答案册写的是 2λ/a = 1.6 rad —— 那是 sinθ≈θ 的近似。本题 θ1 已达 53°，近似误差 16%。考试按答案册写 1.6 rad 可得分，但要知道它是近似。

3能分辨的最小波长差：刻线总数 N = 400 × 50 = 20000，分辨本领 R = mN 要用最大级次
mmax = 3（第 4 级缺级）⇒ R = 3 × 20000 = 6×104
δλ = λ/R = 500 nm / 6×104 = 8.33×10−3 nm
（1）中央峰（单缝包络）全角宽 106.3°（≈1.86 rad；答案册近似值 1.6 rad）；（2）可分辨的最小波长差 8.33×10−3 nm。易错：把“中央峰”当成干涉主极大，会用 2λ/(Nd) 得到 2×10−5 rad 的荒谬结果。
两种“宽”别混：
· 单缝包络中央明纹宽 = 2λ/a（精确为 2 arcsin(λ/a)）—— 由缝宽定，与 N 无关；
· 干涉主极大半角宽 = λ/(Nd) —— 由总刻线数定，描述谱线“细不细”。
本题问“衍射中央峰”，取前者。

2021-二-1条纹间距、水中变化、消失级次、光源临界宽度四问综合
杨氏双缝实验中，双缝间距 d = 0.5 mm，接收屏距双缝 D = 1 m，点光源距双缝 l = 30 cm，点光源发射波长为 500 nm 的单色光，试求：
（1）屏上的条纹间距，若把整个装置放入水中，条纹间距如何变化；
（2）若点光源发出的光波长为（500 ± 2.5）nm 范围内的准单色光，求接收屏上干涉条纹消失时的级次；
（3）若光源具有一定的宽度，屏上干涉条纹消失时，它的临界宽度是多少？
（1）4 分
（2）3 分
（3）3 分
1（1）条纹间距
Δx = λD/d = 500×10−9 × 1 / (0.5×10−3) = 1 mm
2入水后波长变为 λ′ = λ/n（n ≈ 1.33），间距同比例缩小
Δx′ = Δx/n ≈ 1/1.33 ≈ 0.75 mm（条纹变密）
3（2）这是连续谱带（500±2.5 nm，全宽 Δλ = 5 nm），判据是光程差超过相干长度：
Δl = λ2/Δλ = (500 nm)2/5 nm = 50 μm
Δl = mλ ⇒ m = λ/Δλ = 500/5 = 100 级

别用 mΔλ = λ/2 那个判据——那是“两条分离谱线”的错开条件，会得到 50 级，少一半。

4（3）光源宽度使边缘两点的条纹错开一个条纹间距，可见度降到零
b d/l = λ ⇒ b = λl/d = 500×10−9 × 0.30 / (0.5×10−3) = 0.3 mm
Δx = 1 mm；水中 0.75 mm；条纹消失级次 100 级；光源临界宽度 0.3 mm。
两个判据别混：
· 连续谱（准单色光，宽度 Δλ）→ 相干长度 Δl = λ2/Δλ，m = λ/Δλ；
· 两条谱线（间隔 Δλ）→ 条纹错开半个间距，m = λ/(2Δλ)，且随后有“复现”。
本题是前者，答案 100 级。

2021-二-3氟化镁增透膜的厚度、最小反射率、与未镀膜比较

三 · 应用光学 简答题

2018-三-2孔径光阑与入瞳/出瞳；视场光阑与入窗/出窗
对于一个光学系统，什么是孔径光阑，它与入瞳和出瞳的关系是什么？什么是视场光阑，它与入窗和出窗的关系是什么？
5 分

孔径光阑：系统中限制轴上物点成像光束孔径角（光束立体角）的那个光阑，它决定进入系统的光能量和系统的分辨率。

  • 入瞳：孔径光阑经它前方光组所成的像，是物方孔径角的入口；
  • 出瞳：孔径光阑经它后方光组所成的像，是像方孔径角的出口；
  • 三者互为共轭；入瞳对轴上物点的张角即物方孔径角。

视场光阑：限制物平面（或像平面）上成像范围的光阑，决定视场大小。

  • 入窗：视场光阑经前方光组所成的像；
  • 出窗：视场光阑经后方光组所成的像；
  • 入窗对入瞳中心的张角 = 物方视场角；出窗对出瞳中心的张角 = 像方视场角；过入瞳中心的光线叫主光线。
背：光阑→入瞳/出瞳（前/后成像），视场光阑→入窗/出窗；入瞳定孔径，入窗定视场。
【真题 + 教材】
2018-三-4直角棱镜 + 五角棱镜 + 直角棱镜（链）
已知物体为右手坐标系，oz 为光轴方向，作棱镜系统的像方成象坐标方向。
图 · 点此收起 / 展开
5 分
1数反射：直角棱镜 1 次 + 五角棱镜 2 次 + 直角棱镜 1 次 = 4 次。偶数次 ⇒ 右手系（不镜像）。
2光轴：入射 +z → 第一块折向下 → 五角棱镜平移并保持 → 末块折回 +z，故出射光轴与入射平行同向：z′ = z。
3横向两轴：两次直角棱镜各把横向翻一次，叠起来两支都反向 ⇒ 出射坐标系相当于绕光轴转 180°：
x′ = −x，　y′ = −y，　z′ = z
图 · 答案册原图（点此收起）
4 次反射 → 右手系；出射光轴与入射同向（z′ = z），横向两轴均反向（x′ = −x、y′ = −y），即绕光轴旋转 180°。
别只写“三轴同向”：偶数次反射保证的是“不镜像、右手系”，不等于坐标轴方向不变 —— 这里实际转了 180°。判断横向翻转要逐个数每个反射面把哪个轴翻过去。
【真题 + 教材】
2019-三-1完善条件；无穷远物点经单一曲面反射成完善像的面形
光学系统成完善像的条件是什么？试由该条件确定将无穷远的物点经单一曲面反射成完善实像点的曲面形状。
5 分

条件：等光程（轴外点再加正弦条件）。

面形：旋转抛物面。平行光（无穷远物点）沿轴入射，反射后会聚于焦点，焦点就是像点；抛物面上任一点到焦点的距离等于它到准平面的距离，故各条光路光程相等 —— 满足等光程，成完善像。

背：无穷远物点 → 抛物面（焦点即像点）；有限共轭点 → 椭球面（两焦点为物、像点）。
【真题 + 教材】
2019-三-4什么是屋脊棱镜；举例并画平面表示图
什么是屋脊棱镜？试列举一个屋脊棱镜，并给出平面表示图。
5 分

定义：把直角棱镜的一个反射面（通常是斜面）做成 90° 屋脊（两个互相垂直的反射面）的棱镜。屋脊的两个面各反射一次（共两次），使像在垂直于屋脊的方向上倒转，常用于望远系统/双筒望远镜的倒像。

举例：屋脊直角棱镜（阿贝棱镜）、屋脊五角棱镜、屋脊半五角棱镜。

平面表示图画法（答题时按这四步画）：

  1. 画直角棱镜的三角形轮廓（直角在左上，斜边朝右下）；
  2. 把斜边改画成“人”字形折线（两条 45° 线交于屋脊棱），在棱上标 90°；
  3. 画出光线：从前表面入射 → 在屋脊两面各反射一次 → 从另一表面出射；
  4. 用箭头标出出射方向相对入射方向折转 180°（反向），像上下颠倒。

什么是光学系统的像差？下图 (a) 和 (b) 分别给出了物体经过两个光学系统成像后像面，试问这时它们各自主要存在哪种单色像差？

像差：实际像与理想像的偏差（实际波面偏离理想球面波）。

(a) 畸变：正方形像四边内凹、四角外伸，放大率随视场增大 —— 是正（枕形）畸变。像本身仍清晰，只是形状变了（物像不相似）。

(b) 像散：同心圆（切向）与辐射线（弧矢）属于子午、弧矢两个方向，两者不能同时清晰，说明子午像与弧矢像不重合 —— 典型像散（通常伴随场曲）。

答：(a) 畸变（枕形）；(b) 像散。【待核】：(b) 的扫描图样较粗，若答案册判为“场曲”，以教材图为准 —— 像散与场曲在轴上点之外的图上常同时出现，但“两个方向不能同时清晰”这一特征是像散。

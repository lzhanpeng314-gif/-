单球面折射
n′l′ − nl = n′ − nr
逐次成像的主力公式。r 的符号看球心在顶点哪一侧：右为正、左为负。
球面反射镜
1l′ + 1l = 2r
反射公式里不出现折射率。r > 0 球心在镜后（凸面镜），r < 0 为凹面镜。
薄透镜
1l′ − 1l = 1f′
1/f′ = (n−1)(1/r1 − 1/r2)。正弯月 r1、r2 同号且 r1 < r2，f′ > 0。
横向放大率
β = n l′n′l
反射镜用 β = −l′/l。多次成像时 β 要连乘，符号决定正立/倒立。
本章大点 · 反射棱镜题的通用三步
  • ① 展开：把棱镜按像空间展开成一块平行平板，求出展开厚度 L（光在玻璃中走过的总路程）。
  • ② 位移：平板只让像沿光轴移动，不改大小：Δl′ = L(1 − 1/n)。
  • ③ 定轴：按展开后的光轴方向（棱镜把光轴折转的角度）量像的位置，再乘前面的 β 得像高。
棱镜反射次数展开厚度 L
等腰直角棱镜1a（直角边长）
五角棱镜（二次反射）2(2+√2)a
  • 最常错：把五棱镜的 L 记成 2a——差 √2a，像位置能差几十毫米。
  • 自检：n=1 时 Δl′ 应为 0（无玻璃），否则公式代错。

A · 薄透镜 + 全反射膜1 题

A · 薄透镜 + 全反射膜
  • 膜 = 平面镜：先成像，再关于膜面对称
  • 对称后按折转的光轴继续
Δl′ = d(1−1n)
这道的骨架是"逐次成像"：第一面折射 → 第二面反射 → 再经第一面折射。三次都套同一个高斯公式，难点全在符号。
2019-四-1正弯月薄透镜；右面镀全反射膜后像的位置与大小
一折射率为 1.5 的正弯月薄透镜，其左面曲率半径为 5 cm，右面曲率半径为 15 cm，如图 a 所示，该透镜前 30 cm 处有一个高为 1 mm 的物体。
（1）试确定该物体像的大小和位置；
（2）如果在透镜的右面涂上全反射膜，如图 b 所示，试确定这时物体像的大小和位置。

（1）不镀膜：一次薄透镜成像

1先定符号。正弯月透镜两个面同向弯曲，球心都在右侧，故 r1 = +5 cm、r2 = +15 cm；n = 1.5。
1f′ = (n − 1)1r1 − 1r2 = 0.5 × 15 − 115 = 0.5 × 0.1333 = 0.06667 cm−1
f′ = 15 cm
2物在透镜左方 30 cm，取 l = −30 cm，代高斯公式求像距。
1l′ = 1f′ + 1l = 115 + 1−30 = 130
l′ = +30 cm　（正号 = 在透镜右方，实像）
3像高由横向放大率定。
β = l′l = 30−30 = −1，　y′ = β y = −1 × 1 mm = −1 mm
像在透镜右方 30 cm（与物对称），实像，倒立，高 1 mm。物在 2f 处、像也成在 2f 处，这组数正好凑成 β = −1。

（2）右面镀全反射膜：折射 → 反射 → 再折射

4第一次：第一面折射（空气 → 玻璃，n = 1 → 1.5，r1 = +5 cm）
1.5l1′ − 1−30 = 1.5 − 15 = 0.1
1.5l1′ = 0.1 − 0.03333 = 0.06667　⇒　l1′ = +22.5 cm
β1 = n1l1′n1′l1 = 1 × 22.51.5 × (−30) = −0.5

即玻璃里的光会聚在镜后 22.5 cm 处。

5第二次：第二面反射。这面镜在玻璃里，半径仍取几何值 r2 = +15 cm。注意：球心在镜后（右侧），从玻璃里看它是凸面镜，不是凹面镜。会聚光落在镜面上，相当于"虚物" l2 = +22.5 cm。
1l2′ = 2r2 − 1l2 = 215 − 122.5 = 0.13333 − 0.04444 = 0.08889
l2′ = +11.25 cm，　β2 = −l2′l2 = −11.2522.5 = −0.5

l2′ > 0 表示像在镜后（虚像）。反射后光向左走，这束光看起来就是从镜后 11.25 cm 处发散的。

6第三次：光向左再穿过第一面。把光路反过来看：n = 1.5 → 1，曲率半径变号 r3 = −5 cm；那束光从镜后 11.25 cm 处发散出来，对第一面是 11.25 cm 处的实物，l3 = −11.25 cm。
1l3′ − 1.5−11.25 = 1 − 1.5−5 = 0.1
1l3′ = 0.1 − 0.13333 = −0.03333　⇒　l3′ = −30 cm
β3 = n3l3′n3′l3 = 1.5 × (−30)1 × (−11.25) = +4

反向坐标里 l3′ < 0 是虚像，位置在"入射侧"。换回原坐标：透镜右方 30 cm —— 也就是观察者从左侧看进去，像在镜子后面 30 cm。

7三次放大率连乘，得总放大率和像高。
β = β1β2β3 = (−0.5) × (−0.5) × (+4) = +1，　y′ = +1 mm
像在透镜右方（镜后）30 cm，虚像，正立，高 1 mm。与（1）相比：位置同样在右方 30 cm，但由实变虚、由倒变正。
次序作用n → n′r / cml / cml′ / cmβ
①第一面折射1 → 1.5+5−30+22.5−0.5
②第二面反射1.5 → 1.5+15+22.5+11.25−0.5
③再经第一面折射1.5 → 1−5−11.25−30+4
合计右方 30+1
8验算（这题其实等效于一块平面镜）：把反射按 n′ = −n 折成"折射"，三次作用折算到同一平面的总光焦度
Φ = 2Φ1 + Φm = 2 × 1.5 − 15 + (−1.5) − 1.515 = 0.2 − 0.2 = 0

总光焦度为 0、角放大率为 1 ⇒ 系统与平面镜等价 ⇒ 物像关于透镜对称：右方 30 cm、正立、等大。与逐步计算一致。
这就是本题两个曲率半径的"巧合"：(n−1)/r1 = 0.5/5 = 0.1，n/r2 = 1.5/15 = 0.1，正好相等。

B · 三步成像的通用套路方法

B · 三步成像套路
  • ① 选基准面 → ② 透镜成像 → ③ 棱镜展开位移
  • 五棱镜 L = (2+√2)a，不是 2a
应用光学的解析法题，九成是同一个循环：过一面 → 解一次高斯公式 → 记下 β → 下一面。区别只在"这一面是折射还是反射"。
1画光路、定符号：光从左向右，顶点为原点，向右为正；实物 l < 0，实像 l′ > 0。
2每一面写 n′/l′ − n/l = (n′−n)/r；遇到反射面换成 1/l′ + 1/l = 2/r，解出 l′。
3算 β = n l′/(n′l)（反射镜 β = −l′/l），并一路连乘。
4反射之后的第二次折射：把光路反演 —— r 变号、n 与 n′ 互换，解完再把 l′ 的符号翻译回原坐标（"入射侧"= 虚像）。
5收尾用"总光焦度"或"物像对称"粗验算一遍，量级和正倒不对就回头查符号。
四个高频坑
① 反射面在玻璃里时，r 用几何半径、不乘 n；但"凸/凹"要站在入射光一侧看 —— 本题第二面从玻璃里看是凸面镜（r = +15），不是凹面镜。
② 第三次折射别忘 r 变号：+5 要写成 −5，否则整道题的结果全错。
③ β 是三次连乘，符号决定正倒；只拿最后一次的 β 当总放大率是常见失分点。
④ l′ 的"左/右"要在原坐标里说清楚，反向光路的符号极易读反。

2023-三-2（简答）放大镜 5× 的焦距是多少
什么是放大镜的视角放大率？放大倍数 5× 的放大镜焦距多少？
1视角放大率的定义：用仪器后像对人眼的张角 ω′，与不用仪器、把物放在明视距离（250 mm）处时对人眼的张角 ω 之比
Γ = tanω′tanω
2放大镜把物放在前焦点以内，像成在无穷远（正常调节）时，通行的标法是
Γ = 250 mmf′
3代入 Γ = 5
f′ = 2505 = 50 mm
f′ = 50 mm（按"像在无穷远"的通行标法）。若题目约定像成在明视距离处，则 Γ = 1 + 250/f′，解出 f′ = 62.5 mm —— 两种约定要看清题意。

2023-三-3（简答）由等光程条件求旋转对称反射面的方程
关于 z 坐标轴旋转对称的反射曲面经过坐标原点 O，可以将旋转对称轴上实物点 A 反射成像在 A′，如果 AO = 4 cm，AA′ = 2 cm，试基于光完善条件确定反射面的方程。
1建坐标：O 为原点，z 轴沿对称轴、取光传播方向为 +z（向右）。A 在 O 左侧 4 cm ⇒ zA = −4 cm；A′ 在 A 与 O 之间，AA′ = 2 cm ⇒ zA′ = −2 cm。
2光完善条件就是等光程：从 A 出发、经面上任一点 P 反射到 A′ 的光程都相等（反射定律正是它的驻值条件）
|AP| + |PA′| = 常数
3取 P = O（O 在面上）定出常数
常数 = AO + A′O = 4 + 2 = 6 cm
4"到两定点距离之和为常数"的旋转曲面 = 以 A、A′ 为焦点的旋转椭球面：
2a = 6 ⇒ a = 3 cm；　2c = AA′ = 2 ⇒ c = 1 cm；　b2 = a2 − c2 = 9 − 1 = 8 cm2
5椭球中心在 AA′ 的中点 z = −3 cm，故方程为
(z + 3)29 + x2 + y28 = 1　（长度单位 cm）
6验算：O(0, 0, 0) 代入得 9/9 = 1 ✓；另一顶点 z = −6 cm 处 |AP| + |PA′| = 2 + 4 = 6 ✓。
反射面是旋转椭球面：(z+3)2/9 + (x2+y2)/8 = 1（cm）。顶点在 O，另一顶点在 z = −6 cm，A、A′ 是它的两个焦点，反射发生在椭球内表面。
若把 +z 取为向左，则同一曲面写成 (z−3)2/9 + (x2+y2)/8 = 1，只是坐标取向不同。

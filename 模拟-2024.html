2024-1(1)光纤传光的原理与数值孔径
光纤传播应用了什么光学原理？对于纤芯折射率 1.55、包层折射率 1.5 的光纤，其数值孔径是多少？
5 分

原理：全反射。光在纤芯（n1 = 1.55）与包层（n2 = 1.5）界面上，当入射角大于临界角 θc = arcsin(n2/n1) 时发生全反射，光被限制在纤芯内以锯齿形前进。

NA = √(n1² − n2²) = √(1.55² − 1.50²) = √0.1525 ≈ 0.39

数值孔径决定光纤的收光能力，NA 越大能耦合进光纤的光越多。

2024-1(2)杨氏双缝：光源上移 / 增大光源到双缝的距离
杨氏双缝干涉实验中，光源上移，条纹会出现什么变化？增加光源到双缝的距离，条纹如何变化？
5 分

①光源上移：零级条纹向相反方向（下方）平移，整个条纹图样下移；条纹间距不变（Δx = λD/d 只与 D、d 有关）。

②增大光源到双缝的距离：光源的空间相干性变差，条纹可见度下降、逐渐模糊直至消失；条纹间距仍不变。判据是光源宽度对应的相干孔径 θ ≈ λ/b，超过即失去相干性。

2024-1(4)"o 光 n = no，e 光 n = ne" 对不对
有人说，n1 = n1 = no，n3 = ne，则 o 光 n = no，e 光 n = ne，对还是不对，说明理由？
5 分

结论：不对。这句话把 no 和 ne 当成了“两种光各自的折射率”，而它们其实是两个主折射率——只有在特定方向上才对应某一支光。

① o 光：折射率恒为 no，与传播方向无关（这半句成立）。

② e 光：折射率随波法线与光轴的夹角 θ 变化：

1ne(θ)2 = cos2θno2 + sin2θne2

只有θ = 90°（波法线⊥光轴）时才有 ne(90°) = ne；θ = 0（沿光轴）时 ne(0) = no，两支不分开、无双折射。

③ 一句话记法：o 光走哪都是 no；e 光只有“垂直于光轴”时才 ne，沿光轴时退回 no，其余方向介于两者之间。

三种问法是一回事：
·「n1=n2=no、n3=ne，则 o 光 n=no、e 光 n=ne，对吗？」
·「晶体双折射有两个许可折射率 no、ne，这样说对不对？」
·「沿光轴入射会不会双折射？」——不会，因为此时两支折射率都等于 no。
答题时按上面①~③的顺序写，都能拿到分。

【真题 + 教材】
2024-1(5)同一 He-Ne 激光，超净室与实验室看到的一样吗
同一个 He-Ne 激光器发出的光束，在超净室观察与在一般实验室环境观察到的结果一样吗？为什么？
5 分

不一样。

  • 一般实验室空气中悬浮微粒多，激光通过时发生明显的散射（丁达尔现象），能看到一条明亮的光路；
  • 超净室微粒极少，散射很弱，光路几乎看不见。

结论：散射由介质的不均匀性（微粒）引起，不是光本身的性质 —— 这也说明"光路可见"的前提是存在散射体。

2024-三-1完善像条件；单个球面反射镜能否完善成像
成完善像的条件？单个球面反射镜能否成完善像？
5 分

条件：等光程 +（轴外）正弦条件。

单个球面反射镜：一般不能 —— 球面对有限共轭点有球差（只有近轴小光束才近似完善）。能完善成像的只有特殊共轭位置：

  • 物点在球心 C：所有光线沿半径入射、原路返回，像也在 C；
  • 物点在镜面顶点：像与物重合于顶点（平凡情形）。

要在有限共轭距下真正完善成像，面形须是椭球面（两焦点为物、像点）；物在无穷远时须是抛物面。

背：球面镜只有“物在球心”“物在顶点”两处完善，其余有球差。
【真题 + 教材】
2024-三-2像散、场曲的概念及对成像的影响
两个像散，场曲的概念，对成像又有何影响？
5 分

像散：轴外物点发出的细光束经系统后，子午方向与弧矢方向的聚焦位置不同，形成两条互相垂直的短焦线（子午焦线、弧矢焦线），两线之间为最小弥散圆。影响：轴外点不能成清晰的点像，像被拉成椭圆或短线，视场越大越明显。

场曲：即使没有像散，平面物体的像面也不是平面而是曲面（子午场曲、弧矢场曲，两者一般不重合）。影响：用平面探测器接收时，中心调焦清晰则边缘离焦模糊，反之亦然，有效视场受限。

背：像散 = 子午/弧矢焦线分离；场曲 = 像面是弯的；两者都使轴外像质下降，且常同时出现。

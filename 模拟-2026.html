2026-物-1什么影响反射、折射题面仅一句
（回忆原文）一、什么影响反射折射
复原猜测：问反射/折射（反射率、折射角、偏振状态）由哪些因素决定。
5 分
1① 两侧介质的折射率（相对折射率 n21 = n2/n1）：决定折射角（n1sin i1 = n2sin i2）与反射率的大小。
2② 入射角 i1：反射率随 i1 单调增到 100%（掠入射）；i1 > 临界角且 n1 > n2 时发生全反射（临界角 sin ic = n2/n1）。
3③ 波长（色散）：n = n(λ)，故折射角、反射率都随波长变（棱镜分光、彩虹的成因）；金属的反射率还强烈依赖波长（所以金属有颜色）。
4④ 偏振态：菲涅耳公式给出 rs、rp 不同 ——
rs = −sin(i1−i2)sin(i1+i2)　，　rp = tan(i1−i2)tan(i1+i2)

在布儒斯特角 iB（tan iB = n2/n1，此时 i1+i2 = 90°）处 rp = 0，反射光成为纯 s 偏振的线偏振光 —— 这是"反射起偏"的原理。

5⑤ 界面状况：粗糙度（漫反射 vs 镜面反射）、镀膜（多层膜可把 R 从 4% 调到 99.9%）、吸收（复折射率 n + iκ）、以及是否发生全反射。
五个因素：折射率比、入射角、波长（色散）、偏振态（rs≠rp，布儒斯特角处 rp=0）、界面性质（粗糙度/镀膜/吸收）。

2026-物-2菲涅耳透镜与普通透镜的区别题面仅一句
（回忆原文）二、菲涅耳透镜和普通透镜的区别
复原猜测：比较菲涅耳（螺纹/环带）透镜与普通连续面透镜在结构、光学性能、用途上的差异。
5 分
1结构：普通透镜靠连续曲面的厚度变化积累相位；菲涅耳透镜把连续曲面"塌陷"成一系列同心环带（每一环带保留原曲面在该处的倾角/相位，只是把多余的厚度削掉），因此厚度、重量、材料体积都大幅减小。
2光学性能：
优点：可以做很大口径、很轻、很便宜（塑料压铸）；焦距由环带设计决定，可做到 f/D 很小
缺点：环带的台阶造成遮光、杂散光、衍射效率损失（多级衍射），成像质量/分辨率远不如连续面透镜，且对斜入射更敏感（有"环带像差"）
3用途：普通透镜用于成像（相机、显微镜、望远镜）；菲涅耳透镜多用于聚光、照明、投影、太阳能聚光、灯塔、VR 头显等"只要会聚、不要求成像质量"的场合。
4一句话对比：菲涅耳透镜 = "用相位换厚度"；普通透镜 = "用厚度换相位"。前者省材料、能做大；后者成像好。
结构：环带（阶梯）vs 连续曲面；性能：轻/薄/大口径/便宜，但成像质量差、有台阶杂光；用途：聚光照明 vs 成像。

2026-物-4一般性吸收与选择性吸收题面仅一句
（回忆原文）四、一般性吸收和选择性吸收
复原猜测：区分介质对光的"一般（普遍）吸收"与"选择性吸收"，并各举一例。
5 分
1共同规律：朗伯定律 I = I0e−αd（α 为吸收系数，d 为厚度）。
2一般吸收（普遍吸收）：在考察的波段内 α 几乎不随波长变化，对各色光"一视同仁"地吸收 ⇒ 透射光颜色不变，只是变暗。
例：中性灰滤光片、大气对可见光的吸收（灰霾）、玻璃在可见光区的弱吸收
3选择性吸收：α 随波长剧烈变化，某些波段被强烈吸收（吸收带），其余波段透过 ⇒ 透射光呈剩余波段的颜色。
例：红玻璃只透红光、彩色滤光片、晶体的本征吸收带（如半导体在带隙附近的本征吸收）、叶绿素吸收红光蓝光而呈绿色
4两者关系：任何介质都不可能"只选择"或"只一般"——通常一个波段内以选择性吸收为主（特征吸收带），带外表现为一般吸收；这也是"物体有颜色"的根本原因（吸收 + 反射的选择性）。
一般吸收：α 与 λ 无关、只变暗不变色（中性滤光片）；选择性吸收：α 随 λ 剧变、透射光带颜色（彩色玻璃/晶体吸收带）；定量都用 I = I0e−αd。

2026-应-1投影仪器为什么能消除渐晕题面仅一句
（回忆原文）投影仪器为什么能消除渐晕
复原猜测：请说明投影（放映）仪器的照明系统为什么能消除像面渐晕，并指出消除渐晕的条件。
5 分
1渐晕是什么：轴外点发出的、充满孔径光阑的光束，在通过系统时被镜框（或入窗/出窗）切割，参与成像的光束截面变小 → 像面照度从中心向边缘迅速下降，这就是渐晕。
2消除渐晕的充要条件：入射窗与物平面重合（等价地：出射窗与像平面重合）。窗与物面重合时，轴外点与轴上点发出的光束被同一个光阑限制、截面相同，不再随视场增大而被切割。
3投影仪怎么做到的：投影仪的照明系统（聚光镜 + 光源）按柯勒照明（Köhler illumination）设计 —— 把光源成像在投影物镜的孔径光阑（入瞳）处，把照明系统的出射窗成像在物平面（投影片）上。于是：
① 物面被均匀照明（光源的像充满入瞳，各点孔径相同）
② 物面上每一点都以充满入瞳的光束进入物镜 ⇒ 无切割 ⇒ 无渐晕、照度均匀
4对比记忆：临界照明把光源像成在物面上（亮但不均、易烧片）；柯勒照明把光源像成在入瞳上（均匀、无渐晕）—— 投影仪、显微镜都用柯勒。
因为投影仪用柯勒照明：光源成像在物镜入瞳、照明出射窗与物面重合 ⇒ 轴上轴外光束截面相同、不被镜框切割 ⇒ 消除渐晕。判据一句话：窗与物面重合。

2026-应-2设计一个测量光学材料折射率的方法题面仅一句
（回忆原文）设计一个测光学材料折射率的方法
复原猜测：这是一道开放题，要求给出测量原理、光路、公式与注意事项。
5 分
1方案 A（首选，精度最高）：最小偏向角法（棱镜法）
把材料磨成顶角 A 的三棱镜，用单色平行光入射，转动棱镜找到最小偏向角 δmin
n = sin[(A + δmin)/2]sin(A/2)

要点：最小偏向角时入射光与出射光对称（i1 = i2′），读数最灵敏；精度可达 10−5 量级。测 n(λ) 时换不同波长的单色光即得色散曲线。

2方案 B（最快，适合平板/液体）：布儒斯特角法
测 p 分量反射光消光时的入射角 iB　⇒　n = taniB

要点：起偏器 + 检偏器，转动样品找反射光最暗；缺点是精度 ~10−3，且只能测表面。

3方案 C（工程常用）：全反射临界角法（阿贝折射仪）
测临界角 θc：n = 1sinθc（相对空气）　或　nx = n0 sinθc（相对已知标准棱镜 n0）

要点：只需一小块抛光面，读数直接刻度化，适合快速测固体/液体。

4方案 D（薄膜/已加工件）：干涉法——用迈克尔逊或 F-P 干涉测厚度 d 与光程差变化，由 Δ = 2n d 反解 n。
答题模板：选最小偏向角法（写清光路：单色平行光 → 顶角 A 的三棱镜 → 找最小偏向角 → n = sin[(A+δmin)/2]/sin(A/2)），再补一句"也可用布儒斯特角法 n = tan iB 或临界角法 n = 1/sinθc" 显示知识面。

2026-应-3彗差的图像（弥散斑形状）题面仅三字
（回忆原文）慧差图像（"慧差"即"彗差"）
复原猜测：要求画出/说明彗差的弥散斑图形，并解释其成因与特征。
5 分
1图形：轴外物点发出的宽光束经系统后，在像面上形成一个彗星状的弥散斑 —— 一端尖而亮（靠近主光线，能量集中），另一端宽而暗（像"彗尾"）；整体上小下大（或上下颠倒，取决于光阑在上/下方）。
2成因（三步说清）：
① 轴外点发出的光束对系统上下不对称（子午面内上、下光线的孔径不同）
② 各环带（不同孔径 h）的光线在像面上交成一系列半径不同的小圆
③ 这些圆的圆心沿一条直线依次偏移（偏移量 ∝ h2），叠加起来就成了彗星状
3特征与规律（考点密集）：
δy′ ∝ y·h2（与视场一次方、孔径平方成正比）

—— 与球差（∝h²，轴上就有）不同，彗差只在轴外出现，且随视场线性增大；对光阑位置极敏感：移动光阑可使彗差为零（该位置称不晕点/齐明点），这也是"光阑放在透镜上"能消彗差的原因。

4与其它像差区分：球差（轴上、圆对称光斑）／彗差（轴外、彗星状）／像散（轴外、子午与弧矢焦距不同，成两条焦线）／场曲（像面弯曲）／畸变（清晰但变形，无弥散斑）。
彗差弥散斑＝彗星状（一头尖亮、一头宽暗），由轴外宽光束上下不对称 + 各环带圆心沿直线偏移造成；∝ y·h²，只出现在轴外，可用光阑位置（不晕点）消除。

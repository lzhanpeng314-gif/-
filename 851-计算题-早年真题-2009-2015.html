设空气中一单色平面光波的频率为 ν = 1014 Hz，电场强度的振幅大小为 1 V/m。t = 0 时刻，在 xoy 平面（z = 0）上的相位分布如图所示。等相位线与 x 轴垂直，φ = 0 的等相位线坐标为 x = −5 μm，φ 随 x 线性增加，x 每增加 4 μm 相位增加 2π。求该光波电场强度大小的表示式、空间频率及波矢方向。

2等相位线与 x 轴垂直 ⇒ 相位只随 x 变 ⇒ ky = 0，波矢在 xoz 面内。x 每 4 μm 相位增 2π ⇒ 沿 x 的"空间周期"λx = 4 μm
fx = 1λx = 14 μm = 0.25 μm−1 = 2.5×105 m−1
3波矢分量：|kx| = 2π/λx = 1.571×106 m−1，ky = 0
kz = ±√(k² − kx²) = √(2.094² − 1.571²)×106 = 1.385×106 m−1

2011-10给入射方向与界面法线，求反射、折射光线的方向矢量
沿 A0 = i 方向的光线，从 n = 1 的介质入射到 n′ = √3 的介质中，已知界面的法线方向为 n0 = −½i + (√3/2)j，求反射和折射光线的方向矢量。
1入射角：cos θ1 = |A0·n0| = |−½| = 0.5 ⇒ θ1 = 60°
2反射定律（矢量式）：A′ = A0 − 2(A0·n0)n0，代入 A0·n0 = −½
A′ = i + (−½i + √3/2j) = ½i + (√3/2)j

|A′| = √(¼ + ¾) = 1 ✓，且与 A0 关于界面（垂直于 n0）对称。

3折射定律：n sin θ1 = n′ sin θ2
1 × √32 = √3 · sin θ2 ⇒ sin θ2 = ½ ⇒ θ2 = 30°
4在入射面（xoy 面）内取与界面平行的单位矢量 t = (√3/2)i + ½j（t⊥n0，切向分量方向），令指向介质 2 的法线为 −n0，则
A″ = cos30°·(−n0) + sin30°·t = (0.433,−0.750) + (0.433,0.250)
A″ = (√3/2)i − ½j（|A″| = 1 ✓）
反射光线方向 ½i + (√3/2)j；折射光线方向 (√3/2)i − ½j（θ1 = 60°，θ2 = 30°，全在 xoy 面内）。
自检：两矢量都是单位矢量；折射光线与 −n0 的夹角 = 30° = θ2 ✓；切向分量之比 = sin60°/sin30°... 应比较 n·sinθ：1×sin60° = √3/2 = √3×sin30° ✓。

2011-11双平面镜：入射平行一镜、出射平行另一镜，求夹角
有一双平面镜系统，光线与其中的一个镜面平行入射，经两次反射后，出射光线与另一镜面平行，问两平面镜的夹角为多少。
1双平面镜的基本结论：入射光线经两镜依次反射后，偏向角 δ = 2α（α 为两镜夹角，取主截面内计算），且 δ 与入射角无关。
2题设"入射光线 ∥ 镜 1、出射光线 ∥ 镜 2"。出射方向相对入射方向转过的角度，正是两镜方向之间的夹角 —— 但它是 180° − α（出射光被"折回"到另一侧），不是 α。
δ = 2α = 180° − α
3解出
3α = 180° ⇒ α = 60°
4验算（α = 60°，镜 1 取 x 轴、镜 2 与它成 60°）：入射 (1,0) 先在镜 2 上反射得 (cos120°, sin120°)，再在镜 1 上反射得 (cos120°, −sin120°) ∝ −(½, √3/2)，恰与镜 2 的方向 (½, √3/2) 平行 ✓
两平面镜夹角 α = 60°（此时偏向角 δ = 120°，出射光与入射光反向偏折 120°）。
易错：直接写"δ = 2α 且 δ = α ⇒ α = 0"是漏了方向。α = 0 是两镜重合的退化情形，不算解；本题按"光线先被与它成 α 的那面镜反射"取几何，唯一非退化解是 60°。

G · 几何光学：薄透镜与高斯公式3 题

三题全是 1/l′ − 1/l = 1/f′ 与 β = l′/l 联立。符号规则：实物 l < 0、实像 l′ > 0；共轭距取 |l′ − l|。
2012-10β = −1 加贴第二块透镜后像移 20 mm、放大率变 3/4，求两焦距
一个薄透镜对某物体成实像，放大率为 −1，今以另一个薄透镜紧贴在第一透镜上，则发现像向透镜方向移动了 20 mm，放大率为原来的 3/4，求两块透镜的焦距。
1单个透镜：β = l′/l = −1 ⇒ l′ = −l，代入高斯式
1l′ − 1−l′ = 2l′ = 1f1′ ⇒ l′ = 2f1′，l = −2f1′
2贴第二块后：物距不变（l = −2f1′），新放大率 β′ = −3/4
l″ = β′·l = (−0.75)(−2f1′) = 1.5f1′
3像向透镜移动 20 mm：原 l′ = 2f1′ → 新 1.5f1′
2f1′ − 1.5f1′ = 0.5f1′ = 20 mm ⇒ f1′ = 40 mm
4组合焦距：l = −80 mm、l″ = 60 mm
1f′ = 160 + 180 = 7240 ⇒ f′ = 34.3 mm
5密接组合：1/f′ = 1/f1′ + 1/f2′
1f2′ = 7240 − 140 = 1240 ⇒ f2′ = 240 mm
第一块透镜 f1′ = 40 mm，第二块透镜 f2′ = 240 mm（两块都是正透镜，密接后组合焦距 34.3 mm）。

H · 球面折射1 题

曲率中心是自共轭点：过球心的光线不折射，所以"看到鱼在曲率中心"就等于"鱼真的在曲率中心"，剩下的只是纵向放大率。
2014-10球形鱼缸里金鱼的实际位置与实际速度
一个由很薄的均匀玻璃构成半径为 100 cm 的球形鱼缸，其中水的折射率为 4/3，缸内有一条金鱼游向缸壁，某人从缸壁外观察到金鱼沿水平方向游过鱼缸壁的曲率中心，此时速度为 2 cm/s，试问金鱼实际的位置和速度。
1折射球面公式（水 n = 4/3 → 空气 n′ = 1，缸壁极薄可忽略，r = −100 cm，球心在物方）
n′l′ − nl = n′ − nr
2观察到的像在曲率中心（缸壁内 100 cm）⇒ l′ = −100 cm，代入
1−100 − 4/3l = 1 − 4/3−100 = 1300 ⇒ 4/3l = −175 ⇒ l = −100 cm
3即 l = l′ = r —— 鱼就在球心（距缸壁 100 cm）。这一点不用算也成立：过球心的光线法线入射、方向不变，曲率中心永远与自己的像重合。
4速度用纵向放大率：β = nl′/(n′l) = 4/3，α = dl′/dl = (n′/n)β2
α = 34 × 432 = 43，　v视 = α·v实 ⇒ v实 = 24/3 = 1.5 cm/s
金鱼实际位置就在鱼缸壁的曲率中心处（距缸壁 100 cm，即缸心）；实际速度 1.5 cm/s（观察到的 2 cm/s 被放大了 4/3 倍，因为此处 β = 4/3、α = 4/3）。

基本方程

麦克斯韦方程组（无源介质）书 p2
∇·D = 0　∇·B = 0
∇×E = −∂B∂t　∇×H = ∂D∂t
符号：E 电场强度、D 电位移矢量、B 磁感应强度、H 磁场强度
物质方程与折射率书 p2
D = εE　B = μH　J = σE
n = √(εrμr)　v = cn
符号：ε = ε₀εr 介电常数；μ = μ₀μr 磁导率；σ 电导率；v 介质中光速
波动方程书 p2
∇²E − με∂²E∂t² = 0
符号：με = 1/v²，是光波在介质中传播必须满足的方程

平面光波

平面波表达式书 p4
E = A cos(ωt − k·r + φ0)
|k| = 2πλ
符号：ω 角频率；k 波矢；φ₀ 初相位；教材时谐因子取 e−i(ωt−k·r)
能流密度（坡印廷矢量）书 p5
S = E × H
⟨S⟩ = 12Re(E × H*)
符号：⟨S⟩ 平均能流密度即光强 I；单色光下 I ∝ E₀²
相速度与群速度书 p14
vg = vp − λdvpdλ
符号：正常色散时 vg<vp；反常色散时 vg>vp

反射与折射

菲涅耳公式书 p15
rs = −sin(θ1−θ2)sin(θ1+θ2)
rp = tan(θ1−θ2)tan(θ1+θ2)
符号：θ₁ 入射角、θ₂ 折射角；s 分量 ⊥ 入射面，p 分量在入射面内
反射率与透射率书 p16
R = |r|²　T = n2cosθ2n1cosθ1|t|²
符号：正入射时 r = (n₂−n₁)/(n₂+n₁)，R = r²
布儒斯特角书 p18
tanθB = n2n1
符号：此时 θ₁+θ₂ = 90°，反射光只含 s 分量（纯偏振）
全反射书 p19
sinθc = n2n1
tanΔφ2 = √(sin²θ1 − sin²θc)cosθ1
符号：Δφ = φs − φp，全反射时 s、p 分量产生不同相位跃变；Δφ 随入射角变化

偏振

偏振度书 p10
P = Imax − IminImax + Imin
符号：自然光 P = 0，线偏振 P = 1，部分偏振 0<P<1

相干叠加与条纹

两相干光叠加书 p31
I = I1 + I2 + 2√(I1I2) cosφ
符号：φ 为相位差（教材相位差一律用 φ）；φ = 2πΔ/λ，Δ 为光程差
两平面波干涉的条纹间距书 p34
Δx = λsinθ1 + sinθ2
符号：θ₁、θ₂ 为两波与法线（z 轴）的夹角，分居两侧取和、同侧取差
可见度书 p32
V = Imax − IminImax + Imin
符号：等强度时 V=1；光源宽度、谱线宽度都会降低 V
杨氏双缝条纹间距书 p33
Δx = λDd
符号：D 缝到屏距离、d 双缝间距；入水后 λ′=λ/n，Δx 同比例缩小

薄膜干涉

等倾干涉书 p36
2nh cosθ2 = mλ（亮）
2nh cosθ2 = (m+12)λ（暗）
符号：θ₂ 膜内折射角；级次教材用 m；有半波损失时附加 λ/2
牛顿环书 p37
rm = √(mλR)（暗环）
符号：R 透镜曲率半径；中心为暗斑（半波损失）
单层增透膜书 p38
h = λ4n1
Rmin = (n0n2 − n1²n0n2 + n1²)²
符号：要求 n₀<n₁<n₂；h 为膜厚（光学厚度 λ/4）

相干性与多光束

相干长度（时间相干性）书 p38
Δlmax = λ²Δλ
mmax = λΔλ
符号：连续谱宽 Δλ；条纹消失级次 m=λ/Δλ（不是 λ/2Δλ）
空间相干性书 p38
dc = λθ　Ac = (λθ)²
符号：θ 光源对双缝张角；临界宽度 b = λl/d
F–P 透射谱线半宽度书 p43
Δλ1/2 = λ²(1 − R)2πnh√R
符号：R 镜面反射率；R 越大条纹越锐；干涉滤光片的带宽即由它决定
法布里–珀罗干涉仪书 p42
2nh cosθ2 = mλ
ΔλFSR = λ²2nh
符号：ΔλFSR 为自由光谱范围；分辨本领 A = mNeff

夫琅禾费衍射

单缝衍射书 p67
I = I0(sinαα)²　α = πa sinθλ
符号：a 缝宽、θ 衍射角；教材单缝参量用 α（不是 u）；中央明纹半角宽 λ/a
圆孔衍射与爱里斑书 p69
θ1 = 1.22λD
符号：D 圆孔直径；爱里斑占中央能量 83.8%
光学仪器分辨本领书 p70
θmin = 1.22λD（望远镜）
δ = 0.61λNA（显微镜，NA = n sinu）
符号：NA 数值孔径；照相物镜用 N = 1/ε 表示相对孔径倒数
多缝（光栅）强度分布书 p71
I = I0(sinαα)²(sinNβsinβ)²
β = πd sinθλ
符号：α 单缝因子、β 相邻缝相位差的一半；N 缝数、d 光栅常数

光栅

光栅方程（正/斜入射）书 p71
d sinθ = mλ
d(sinθ ± sinθ0) = mλ
符号：θ₀ 斜入射角；级次教材用 m
缺级与最大级次书 p72
da = mn
mmax = dλ
符号：d/a 为整数时第 m 级缺级；最大级次由 sinθ≤1 定
谱线半角宽度书 p72
Δθ = λNd cosθ
符号：N 总刻线数；主极大半角宽，与色散相乘即分辨本领
色散与分辨本领书 p72
Dθ = dθdλ = md cosθ
A = λΔλ = mN
符号：N 总刻线数；A 取最大级次 mmax 时最大
斜入射的最大级次书 p72
mmax = d(1 + sinθ0)λ
符号：θ₀ 斜入射角；两侧级次不再对称，一侧 (1+sinθ₀)、另一侧 (1−sinθ₀)
自由光谱范围书 p73
Δλ = λm
符号：m 级与 m+1 级光谱不重叠的波长范围

菲涅耳衍射

菲涅耳半波带书 p74
ρN = √(Nλ / (1R + 1r0))
符号：R 波面曲率半径、r₀ 观察点到波面距离；N 带数
圆孔/圆屏中心强度书 p75
A(P) = a12 ± aN2
符号：圆孔取 ±；圆屏只剩下 a₁/2 ⇒ 中心恒为亮斑（泊松亮斑）
波带片书 p76
1R + 1r0 = 1f
f = ρN²Nλ
符号：波带片有多个焦点（主焦点与次焦点）

单轴晶体

e 光折射率随方向变化书 p103
1ne²(θ) = cos²θno² + sin²θne²
符号：θ = 波法线与光轴夹角（教材 θ 就是波法线角）；θ=0 时 ne(0)=no，不分开
离散角书 p104
tanα = sinθcosθ(ne² − no²)no²sin²θ + ne²cos²θ
符号：α 为波法线与光线（能流）的夹角，教材就用 α（不是 ρ）；正晶体光线靠近光轴、负晶体远离
e 光最大离散角书 p106
tanθ = neno
αM = arctanne² − no²2none
符号：θ 为取最大离散角时的波法线方向与光轴夹角；αM 为该晶体的最大离散角（书 p106）
相速度与光线速度书 p103
vp = vr cosα
符号：vp 沿波法线、vr 沿光线方向；能量沿光线传播
界面折射（双折射）书 p106
n1 sini = no sinro = ne(θ) sinre
符号：折射定律约束的是波法线，不是光线方向
平行平板内两光的横向间距书 p106
s = d tanα
符号：d 平板厚度、α 离散角；掠入射时换成 s = d(1 − tanro/tanre) 之类的几何式

折射率椭球与波片

折射率椭球书 p105
x1²/n1² + x2²/n2² + x3²/n3² = 1
符号：主轴方向即三个主介电方向；单轴时 n₁=n₂=no、n₃=ne
波片相位延迟书 p107
φ = 2πλ|no − ne|d
符号：φ=π/2 为 λ/4 波片、φ=π 为 λ/2 波片；教材波片相位差用 φ（不是 δ）
偏振棱镜视场书 p106
arcsin(1/no) < θ < arcsin(1/ne)
符号：靠全反射丢掉一支光，只在两个临界角之间有效

电光效应

折射率椭球的变化书 p131
ΔBij = γijkEk + hijpqEpEq + ⋯
符号：第一项线性电光（泡克耳斯）、第二项二次电光（克尔）；γ 线性电光系数
KDP 纵向运用的相位差书 p132
φ = 2πλno³γ63U
符号：纵向：电场 ∥ 通光方向；相位差只与 U 有关、与晶体长度无关
半波电压书 p133
Uλ/2 = λ2no³γ63
符号：使相位差达到 π 所需的电压
KDP 横向运用书 p133
φ = 2πλ[(no − ne)d + 12no³γ63E3l]
符号：横向：电场 ⊥ 通光方向；含自然双折射项 (no−ne)d，需补偿
克尔效应（二次电光）书 p134
Δn = KλE²
符号：K 克尔常数；与 E² 成正比

声光与磁光

布拉格衍射的频移书 p134
Δν = ±fs（±1 级）；0 级 Δν = 0
符号：声子图像：±1 级各吸收/放出一个声子，故频移恰为一个声频；喇曼–乃斯第 m 级为 m·fs
声波波长与声频书 p134
λs = vsfs
符号：vs 声速、fs 声频；声频升高 → 声波波长变短 → 布拉格角变大、衍射光频移变大
喇曼–乃斯衍射（声频低时）书 p134
λs sinθ = mλ
符号：声频低、声光作用长度短时为多级衍射；与布拉格衍射的判据是声光作用长度是否足够长
布喇格衍射条件书 p134
sinθB = λ2λs
符号：λs 声波波长；θB 布喇格角
法拉第效应书 p134
θ = VBl
符号：V 费尔德常数、B 磁感应强度、l 介质长度；指导书只给定性叙述

吸收与色散

朗伯定律书 p141
I = I0e−Kl
符号：K 吸收系数、l 介质厚度；比尔定律中 K = αc
科希色散公式书 p142
n = A + Bλ² + Cλ⁴
符号：正常色散区适用；n 随 λ 增大而减小
色散率书 p142
ν = dndλ
符号：dn/dλ<0 为正常色散、>0 为反常色散（吸收带附近）

散射

瑞利散射书 p143
I(θ) ∝ 1λ⁴(1 + cos²θ)
符号：微粒线度 ≪ λ/10 时成立；天空蓝、夕阳红的成因
米氏散射书 p143
I(θ) ∝ 1λn
符号：微粒线度与 λ 相当或更大；n 约 1~3

▾第 7 章 · 几何光学基础12 条

符号规则

符号法则书 p149
l 实物为负、实像 l′ 为正；r 凸向物方为正；f′>0 会聚
符号：正方向 = 光的传播方向（从左向右）；横向线度光轴上为正；角度顺时针为正

球面与薄透镜

单球面折射（近轴）书 p153
n′l′ − nl = n′ − nr
符号：教材就是带减号的写法（不是 n/l + n′/l′）；n′ 像方折射率
阿贝不变量与光焦度书 p153
n′u′ − nu = hn′ − nr
符号：u 孔径角、h 入射高度；光焦度 φ = (n′−n)/r（小写 φ）
焦距书 p154
f′ = n′rn′ − n
f = −nrn′ − n
符号：两侧同介质时 f = −f′
共轭距与放大率、焦距的关系书 p155（例题）
L = |l′ − l| = −f′(1 − β)²β
符号：L 物像间距离（共轭距）；已知 L 与 β 可直接解 f′，实物/虚物各得一解
薄透镜（空气中）书 p154
1f′ = (n − 1)(1r1 − 1r2)
符号：双凸 r₁>0、r₂<0；两侧介质不同要改用光焦度 φ
纵向放大率书 p154
α = dl′dl = nn′(l′l)²
符号：轴线上物点移动 dl 时像移动 dl′；球形鱼缸那道题求速度就用它
平面折射（视深）书 p154
h′ = n2n1h
符号：从空气看水中变浅为 3/4；横向尺寸不变

棱镜展开

等效平行平板像面位移书 p154
Δl′ = d(1 − 1n)
l2′ = l1′ + Δl′
符号：d 为平板（或展开后的棱镜）厚度、n 为玻璃折射率；像沿光轴外移 Δl′，大小不变
折合光程等价的算法书 p154
l′ = d镜距 + Ln + s′
符号：与上条的位移式代数等价：先求展开厚度 L，再用 L(1−1/n) 得位移；两种写法结果相同
一次反射直角棱镜教材第 7 章（指导书未给）
L = a
符号：a 为直角边长；展开成等效平板
二次反射五棱镜教材第 7 章（指导书未给）
L = (2 + √2)a ≈ 3.414a
符号：a 为通光面边长；不是 2a，用错会把像距算偏约 50 mm

成像公式

高斯公式（教材写法）书 p169
f′l′ + fl = 1
符号：f′/f = −n′/n；两侧同介质（n=n′）时化为 1/l′ − 1/l = 1/f′
牛顿公式书 p169
xx′ = ff′
符号：x 从物方焦点量起、x′ 从像方焦点量起
光焦度与焦距书 p169
φ = n′f′ = −nf
符号：教材光焦度用小写 φ（不是 Φ）
三组放大率书 p170
β = nl′n′l
γ = xl′x′l
符号：β 垂轴、α 轴向、γ 角放大率；同一对共轭面上三者满足 α = β² 等关系
二次成像法求焦距书 p174（例题）
1β1 − 1β2 = df
符号：同一透镜两次成像：物移动 d、放大率由 β₁ 变 β₂；由此反求 f′（2021-四-2）

双光组

组合焦距与光学间隔书 p171
Δ = d − f1′ + f2
f′ = −f1′f2′Δ
符号：d 两透镜间隔；Δ 为光学间隔（F₁′ 到 F₂ 的距离）
后截距与主点书 p171
lF′ = f′(1 − df1′)
lH′ = lF′ − f′
符号：lF′ 从第二透镜量起、lF 从第一透镜量起，原点不同不能混

▾第 9 章 · 光学系统像差基础与光路计算9 条

光阑

孔径光阑与入瞳/出瞳书 p189
入瞳：孔径光阑经其前面所有透镜所成的像
出瞳：孔径光阑经其后面所有透镜所成的像
符号：判定孔径光阑比较的是张角（不是直径）
视场光阑与入窗/出窗书 p190
入窗：视场光阑经其前方系统的像
出窗：视场光阑经其后方系统的像
符号：线视场 2y；渐晕系数 KD（线）、KS（面）

像差

球差书 p191
δL′ = L′ − l′（轴向）
δT′ = T′ − l′（垂轴）
符号：轴上点、只与孔径有关；校正困难，通常保留一定量
像差总览：五种单色 + 两种色差书 p191
球差 · 彗差 · 像散 · 场曲 · 畸变
位置色差 · 倍率色差
符号：记住两条线索：哪种像差与孔径有关（球差、彗差的一部分）与哪种只与视场有关（像散、场曲、畸变）
球差书 p191
δL′ = L′ − l′（轴向球差）
δT′ = δL′ tanU′（垂轴球差）
符号：轴上点、只与孔径有关；U′ 为孔径角；球差使光束不再交于一点，弥散斑半径即 δT′
彗差书 p191
彗差 = 轴外点宽光束失去对称性形成的彗星状弥散斑
符号：与孔径和视场都有关；主光线两侧光束不对称即产生彗差；孔径光阑位置影响彗差大小
像散与场曲书 p191
子午焦线 t′、弧矢焦线 s′（两焦线不重合即像散）
场曲：清晰像面是曲面（匹兹伐面）
符号：都随视场增大而增大（∝ 视场²）；像散使轴外点成两条焦线，场曲使平面物不能在平面上清晰成像
畸变书 p191
Δy′ = y′ − y0′（y0′ 为理想像高）
相对畸变 q = Δy′y0′ ×100%
符号：∝ 视场³；只改变像的形状、不影响清晰度；q>0 枕形、q<0 桶形
色差书 p192
位置色差 Δl′FC = l′F − l′C
倍率色差 Δy′FC = y′F − y′C
符号：F、C 为氢蓝、氢红谱线；位置色差影响轴上点清晰度、倍率色差使像带彩色边缘

▾第 10 章 · 光学仪器的基本原理7 条

眼睛与眼镜

屈光度与校正书 p199
Φ = 1f′（f′ 以 m 计，单位 D）
远点 R = 1/r，近点 P = 1/p，调节能力 A = R − P
符号：近视为 −Φ；远视取 +(4 − A) 一类修正式；5 m 看不清 → 远点 5 m，度数 = 1/5 = 200 度

放大率

放大镜书 p199
Γ = 250f′
符号：f′ 以 mm 计；像在明视距离 250 mm 时成立

一 · 物理光学 简答题

2019-1(1)干涉与衍射的本质联系与区别
光的干涉和光的衍射本质上的联系与区别是什么？
5 分

联系：本质都是相干光波叠加引起的光强重新分布；衍射可以看作无限多个连续分布的次波之间的干涉。

区别：

  • 干涉是有限个（分立）相干光波的叠加；
  • 衍射是无限多个连续次波的叠加，且伴随光偏离直线传播、出现明暗条纹。

2019-1(3)斜入射平面光栅的光栅方程及各量意义
写出光波斜入射平面光栅时的光栅方程，并说明方程中各量的物理意义。
5 分
d ( sin i ± sin θ ) = kλ
  • d：光栅常数（相邻两缝间距）；
  • i：入射角（入射光与光栅法线夹角）；
  • θ：衍射角；衍射光与入射光在法线同侧取"+"、异侧取"−"；
  • k：衍射级次（0, ±1, ±2…）；λ：波长。

意义：相邻两缝对应光线的光程差等于 kλ 时，该方向上各缝衍射光同相叠加，形成主极大。正入射时 i = 0，退化为 d sinθ = kλ。

2019-1(4)沿光轴入射 / 光轴平行表面正入射，会不会双折射
两种入射情况：1）光波沿晶体的光轴入射；2）若光轴平行于晶体表面，光波正入射于晶体表面。问这两种情况下是否会发生双折射现象？请说明理由。
5 分

①沿光轴入射：不发生双折射。此时 o 光与 e 光传播方向相同、速度也相同（都等于 no），两束光不分开。

②光轴平行于表面、光垂直入射：发生双折射。此时光轴垂直于传播方向，o 光与 e 光速度不同（分别为 no、ne），产生双折射 —— 但因两者仍沿法线传播，传播方向相同，只是速度不同（不分开）。

同类问法见 2024-1(4)：ne 只在波法线⊥光轴时才叫 e 光折射率。

2019-1(5)由 dn/dλ 的符号判断色散类型
dn/dλ 表示介质折射率随波长改变的变化率，即为色散率。当色散率 dn/dλ < 0 和 dn/dλ > 0 时，相应介质的光色散类型是什么？
5 分
  • dn/dλ < 0：折射率随波长增大而减小，V > Vg → 正常色散；
  • dn/dλ > 0：折射率随波长增大而增大，V < Vg → 反常色散。

补充：正常色散出现在远离吸收带的区域；反常色散出现在吸收带附近。

某光源发出波长很接近的两单色光，平均波长为 600 nm，通过间隔 d = 10 mm、腔镜反射率为 0.98 的法布里–珀罗干涉仪观察时，看到波长为 λ1 的光所产生的干涉条纹正好在波长为 λ2 的光所产生干涉条纹的中间，试求：两单色光的波长差；在接近正入射时，此干涉仪的分辨本领？（取平均波长为 600 nm）

F = π√R1 − R = π√0.981 − 0.98 ≈ 155.5
Rp = k·F ≈ 3.33×104 × 155.5 ≈ 5.2×106

10 分

sinθ1 = λ/a = 0.5/0.625 = 0.8 ⇒ θ1 = 53.13°

答案册写的是 2λ/a = 1.6 rad —— 那是 sinθ≈θ 的近似。本题 θ1 已达 53°，近似误差 16%。考试按答案册写 1.6 rad 可得分，但要知道它是近似。

mmax = 3（第 4 级缺级）⇒ R = 3 × 20000 = 6×104

· 单缝包络中央明纹宽 = 2λ/a（精确为 2 arcsin(λ/a)）—— 由缝宽定，与 N 无关；

2019-二-4λ1 的 1/4 波片对 λ2 是什么波片
已知方解石对波长 λ1 = 405 nm 光波的主折射率为 no = 1.6813，ne = 1.4969；对波长 λ2 = 710 nm 光波的主折射率为 no′ = 1.6521，ne′ = 1.4836。若一束波长为 λ2 的左旋正椭圆偏振光入射到相应于波长为 λ1 的方解石 1/4 波片上，求：（1）λ1 光波通过该波片时，所产生的相位差？（2）对于 λ2 光波而言，判断该波片是哪种波片？（3）出射光束的偏振态？
（1）4 分
（2）3 分
（3）3 分

（1）

1定义就是答案：既然它是"对 λ1 的 1/4 波片"，则 λ1 通过时的相位差
δ1 = 2πλ1(no − ne)d = π2 = 90°，　且 (1.6813 − 1.4969)d = 4054 nm = 101.25 nm
⇒ d = 101.25 nm0.1844 = 549.1 nm

（2）

2同一块片对 λ2：
δ2 = 2πλ2(no′ − ne′)d = 2π710×10−9 × 0.1685 × 549.1×10−9 = 2π × 0.1303 = 0.819 rad = 46.9°

也可用比例一步算：δ2/δ1 = Δn′Δn · λ1λ2 = (0.1685/0.1844)(405/710) = 0.521 ⇒ δ2 = 0.521 × 90° = 46.9°。

3判据：46.9° 既不是 90°（1/4 波片）也不是 180°（1/2 波片）、更不是 360°。对 λ2 而言它只是一块"任意波片"，光程差 0.13λ（相当于约 1/8 波片，介于 1/8 与 1/4 之间）。

（3）

4入射为正椭圆——椭圆主轴恰沿 o、e 振动方向，这要求 δin = ±90°。叠加该片 46.9°：δout = δin + 46.9°。
左旋 ⇒ δin = −90°，δout = −43.1°，符号未变 ⇒ 旋向不变，仍是左旋。
因 δout ≠ ±90°，主轴不再沿 o/e，转过一个角度、轴比也变；具体取决于入射椭圆轴比（题未给），只能定性。
通用规律：加波片后 δ → δ+Δ，只有越过 0 或 ±180° 才翻转旋向。
（1）δ1 = 90°（d = 549.1 nm）；（2）对 λ2 它不是 1/4 波片，只是一块 δ ≈ 46.9° 的任意波片（光程差 0.13λ）；（3）出射仍为左旋椭圆偏振光（δout = −43.1°，符号未变），主轴方位与轴比改变。【待核】题面没有给入射"正椭圆"的轴比，所以第（3）问只能定性：主轴转角与轴比的具体数值取决于入射椭圆度；若把"正椭圆"理解为圆偏振（轴比 1），则出射为总相位差 90°+47° = 137° 的椭圆、长轴与 x 轴成 45°，轴比（短/长）= |tan(137°/2)|−1 ≈ 0.39。
符号到底怎么定？（容易绕晕的地方）
① δ 的定义随你便，但要一次定死：取“迎着光看、右为 x、上为 y”，δ = φy−φx。若你把两轴对调，δ 反号、左/右旋的标签也同时反号，物理结论不变——所以“谁减谁”本身不需要猜。
② “正椭圆”给出的只有大小：主轴沿 o、e ⇒ |δin| = 90°，具体是 +90° 还是 −90°，由“左旋/右旋”这句话决定（左旋 ⇒ δin = −90°）。
③ 波片加的是“慢轴落后 Δ”：Δ = 2π|n慢−n快|d/λ。写成 δ 时要按你选的轴决定是 +Δ 还是 −Δ，但——
④ 本题不需要这个符号：|δin| = 90°，|Δ| = 46.9° < 90°，无论加还是减，δout 都落在 (−180°, 0°) 内，符号不可能翻。这就是“旋向不变”的依据。
⑤ 会翻的情况：|Δ| ≥ |δin| 且方向使 δ 越过 0（如 λ/4 片遇上 ±90° 入射 → δ=0 变线偏振；λ/2 片 Δ=180° → 必翻）。

三 · 应用光学 简答题

2019-三-1完善条件；无穷远物点经单一曲面反射成完善像的面形
光学系统成完善像的条件是什么？试由该条件确定将无穷远的物点经单一曲面反射成完善实像点的曲面形状。
5 分

条件：等光程（轴外点再加正弦条件）。

面形：旋转抛物面。平行光（无穷远物点）沿轴入射，反射后会聚于焦点，焦点就是像点；抛物面上任一点到焦点的距离等于它到准平面的距离，故各条光路光程相等 —— 满足等光程，成完善像。

背：无穷远物点 → 抛物面（焦点即像点）；有限共轭点 → 椭球面（两焦点为物、像点）。
【真题 + 教材】
2019-三-2费马原理的内容；用它解释直线传播
费马原理的内容是什么？试用该原理解释光在均匀各向同性的介质中沿直线传播。
5 分

内容：光从一点传播到另一点，其实际路径使光程取极值（极小、极大或稳定值），即光程的一阶变分为零：

δ∫AB n ds = 0

解释直线传播：均匀各向同性介质中 n = 常数，光程 = n × 几何路程；两点间几何路程以直线最短，故光程也最小，光沿直线传播。

背：费马 = 光程取极值（δ∫n ds = 0）；均匀介质 n 为常数 → 直线最短 → 直线传播。
【真题 + 教材】
2019-三-3景深定义、影响因素；增大景深怎么调光圈
什么是光学系统的景深？景深的大小受哪些因素影响？照相时为了增加景深，光圈应该增大还是减小？
5 分

景深：在像面上能成清晰像的物空间深度（= 远景深度 + 近景深度），即物平面前后能清晰成像的范围。景深端点对应弥散圆直径等于允许值。

影响因素：

  • 光圈（相对孔径）：越小（F 数越大）景深越大；
  • 焦距：越短景深越大；
  • 摄距：越远景深越大；
  • 允许弥散圆：越大景深越大。

增加景深：缩小光圈（增大 F 数）。

背：景深 ∝ 1/光圈、∝ 1/焦距²、∝ 摄距²；要景深就收小光圈。
【真题 + 教材】
2019-三-4什么是屋脊棱镜；举例并画平面表示图
什么是屋脊棱镜？试列举一个屋脊棱镜，并给出平面表示图。
5 分

定义：把直角棱镜的一个反射面（通常是斜面）做成 90° 屋脊（两个互相垂直的反射面）的棱镜。屋脊的两个面各反射一次（共两次），使像在垂直于屋脊的方向上倒转，常用于望远系统/双筒望远镜的倒像。

举例：屋脊直角棱镜（阿贝棱镜）、屋脊五角棱镜、屋脊半五角棱镜。

平面表示图画法（答题时按这四步画）：

  1. 画直角棱镜的三角形轮廓（直角在左上，斜边朝右下）；
  2. 把斜边改画成“人”字形折线（两条 45° 线交于屋脊棱），在棱上标 90°；
  3. 画出光线：从前表面入射 → 在屋脊两面各反射一次 → 从另一表面出射；
  4. 用箭头标出出射方向相对入射方向折转 180°（反向），像上下颠倒。
背：屋脊棱镜 = 斜面做成 90° 双反射面的棱镜；两次反射、像沿垂直屋脊方向倒转；例：屋脊直角棱镜。

第一步：把共轭面翻译成基点

  • β = +1 的一对共轭面就是主平面：H = π1，H′ = π1′；
  • β = −1 的一对共轭面在 2f 处（薄透镜物在 2f 时像在 2f、β = −1），故 F 是 π1π2 的中点，F′ 是 π1′π2′ 的中点。

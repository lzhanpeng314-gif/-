2025-一-1F-P 干涉仪：透射条纹与反射条纹的区别
法布里-波罗干涉仪透射光的干涉条纹跟反射光的干涉条纹的区别？
1两套条纹是互补的。设镜面反射率 R、透射率 T（吸收略去），精细度系数 F = 4R/(1−R)²，δ 为相邻两束的相位差
IT = IiT2(1−R)211+F sin2(δ/2)　，　IR = IiF sin2(δ/2)1+F sin2(δ/2)
2透射光：极大处 IT = Ii，极小处几乎为 0 ⇒ 暗背景上的细亮纹；反射光：极大处接近 Ii，只在 δ = 2kπ 处掉到很小 ⇒ 亮背景上的细暗纹。
3二者满足 IT + IR = Ii（无吸收时），一条亮一条就暗，明暗位置互换。
一句话：透射＝暗底上的细亮纹，反射＝亮底上的细暗纹，两者互补；R 越大，亮纹越细锐。

2025-一-2平行平板：透射/反射图样之别、工程上用哪个、等倾条纹对光源的要求
平行平板多光束干涉透射光和反射光图样的区别，工程上一般使用透射光还是反射光？等倾干涉条纹要清晰对光源有什么要求？
1图样区别：与一·1 完全同构 —— 透射光是暗背景上的细亮纹，反射光是亮背景上的细暗纹（互补）。
2工程上用透射光：反射条纹是"亮背景上的细暗纹"，背景太亮、暗纹对比度低，眼睛和探测器都不易辨别；透射条纹背景黑、亮纹锐，信噪比高。
3对光源的要求（把答案册两条展开成可背的四条）：
① 单色性要好　② 相干性要好（时间相干：2nh cosθ ≤ 相干长度）

③ 观察等倾圆环要用扩展光源 + 会聚透镜（同一入射角的光会聚到焦面同一点，才形成同心圆环）；④ 平板两表面要平行、平整（面形误差直接叠加到条纹上）。

用透射光；光源要单色性好、相干性好（并配扩展光源 + 会聚透镜看等倾环）。

2025-一-3F-P 与光栅分光原理之别；大范围分光选哪个、为什么
FP 干涉仪和光栅分光的原理有什么区别，一般在较大范围内分光采用那种元件，为什么？
1原理不同：F-P 用多光束干涉（等倾多光束干涉，靠相邻光束的相位差 δ = (4π/λ)·nh·cosθ 选频）；光栅用多缝衍射（靠 d sinθ = kλ 把不同波长送到不同方向）。
2自由光谱范围 Δλ = λ/k 决定"能一次看多宽"：
光栅：k = 1~2　⇒　Δλ ≈ 250~500 nm（覆盖整个可见区）
F-P 标准具：k = 2nh/λ ≈ 4×104（h = 1 cm）　⇒　Δλ = λ/k ≈ 0.0125 nm
3所以大范围分光用光栅光谱仪：级次低、自由光谱范围大、不重叠；F-P 级次高到 10⁴–10⁵，只能在极窄波段内工作（专门用来分辨谱线的精细/超精细结构，分辨本领极高）。
原理：干涉 vs 衍射；大范围分光选光栅（Δλ = λ/k 大）；F-P 级次 10⁴–10⁵，只能用来看极窄波段。

2025-一-4白纸上的黑点，盖上方解石看什么
在一个白纸上画一个黑点，用方解石晶体放在纸上观察黑点能看到什么现象？
1现象：看到两个清晰的黑点（双像）。
2原因：方解石（CaCO₃）是负单轴晶体（no = 1.658 > ne = 1.486）。自然光斜射入晶体后分解为 o 光（遵守折射定律、振动垂直于主截面）和 e 光（一般不遵守折射定律、振动在主截面内），两束传播方向不同，各自成一个像 ⇒ 双折射双像。
3可加分的观察细节：转动晶体时，o 光的像不动，e 光的像绕 o 光的像转动；沿光轴方向观察时两像重合、只剩一个。
两个黑点（双折射双像）；转晶体时一个不动、一个绕转；沿光轴看只有一个。

2025-一-5暗室里 45°、90°、180° 看到的瑞利散射光强比
自然光射入一间暗室，分别从 45°、90°、180° 观察，观察到的瑞利散射光强比是多少？
1瑞利散射（微粒线度 ≪ λ）对自然光入射的角分布
I(θ) = Iz(1 + cos2θ)　（θ 为观察方向与入射光传播方向的夹角；另有 1/λ4 因子）
2逐项代入
I(45°) = Iz(1 + 0.5) = 1.5Iz　；　I(90°) = Iz　；　I(180°) = Iz(1 + 1) = 2Iz
3取比
1.5 : 1 : 2 = 3 : 2 : 4
4顺带记：90° 方向的散射光是完全线偏振的（振动垂直于观察面），180° 方向仍是自然光 —— 这是"天空为什么蓝、且偏振"的同一套公式。
I(45°) : I(90°) : I(180°) = 3 : 2 : 4。

2025-二-1自然光垂直入射玻璃：反射/透射的振幅、强度与偏振度
一束振幅为 A 的自然光从空气垂直入射到折射率为 1.5 的玻璃上。（1）反射光和透射光的振幅和强度。（2）反射光和透射光的偏振度。
1自然光可分解为两个振动方向正交、强度相等、互不相干的分量，各占一半：
Eis = Eip = A√2　，　Iis = Iip = A2/2
2正入射的菲涅耳系数（n1 = 1，n2 = 1.5）
rs = rp = n1−n2n1+n2 = −0.52.5 = −0.2　，　ts = tp = 2n1n1+n2 = 0.8
3振幅：
Ers = Erp = 0.2 × A√2 = 0.1414A　⇒　Er = √2 × 0.1414A = 0.2A
Ets = Etp = 0.8 × A√2 = 0.5657A　⇒　Et = √2 × 0.5657A = 0.8A
4强度：反射率 R = r2 = 0.04，透射率 T = 1 − R = 0.96
Ir = 0.04Ii = 0.04A2　，　It = 0.96Ii = 0.96A2
这里有个必踩的坑：玻璃里的光强按 I = ½nε0cE2 算，所以 不能把 Et = 0.8A 直接平方得 0.64 —— 必须乘 n2/n1 = 1.5：0.82×1.5 = 0.96，才与能量守恒一致。
5偏振度：正入射时 rs = rp、ts = tp，两个分量受到完全相同的处理
Pr = |Irs−Irp|Irs+Irp = 0　，　Pt = 0
振幅：反射 0.2A、透射 0.8A；强度：反射 4%、透射 96%；反射光与透射光都仍是自然光，偏振度均为 0。
【真题 + 自算】结论与手写答案册第 2 页一致（答案册另记 Tn = 0.96、Pr = Pt = 0）
2025-二-2双光源 S、S′ 分别开/同时开时的干涉光强分布
如图，杨氏双缝干涉，S′ 与 S 分别为两个点光源。（1）若 S′S1 − S′S2 = λ/2，求 S 开或 S′ 开或同时开时的干涉光强分布；（2）若 S′S1 − S′S2 = λ，求 S 与 S′ 同时开时的干涉光强分布。
1S 单独开（轴上点光源）：屏上一点 P(y) 的光程差 Δ1 = dy/D，d 为缝距、D 为缝到屏距
I1 = 2I01 + cos2πdλDy　，　条纹间距 Δy = λD/d
2S′ 单独开：S′ 到两缝本就有路程差 δ0，屏上总光程差 Δ2 = dy/D + δ0。

（1）δ0 = λ/2（相当于附加 π 相位）：

I2 = 2I01 + cos(2πdλDy + π) = 2I01 − cos2πdλDy

即 两套条纹明暗互换（互补，间距相同、整体错开半个条纹）。

3同时开：S 与 S′ 是两个独立点光源，互不相干，只能强度相加
I = I1 + I2 = 4I0 = 常数

互补的两套条纹叠加成均匀照明，条纹完全消失（对比度 V = 0）。

4（2）δ0 = λ（附加 2π 相位）：两套条纹完全重合
I2 = I1　⇒　I = 2I1 = 4I01 + cos2πdλDy

条纹位置、间距都不变，亮纹强度加倍（2I0×2×2 = 8I0），对比度仍为 1。

（1）S 开、S′ 开各得互补正弦条纹（2I0(1±cos)），同时开 ⇒ I = 4I0 均匀，条纹消失；（2）同时开 ⇒ I = 4I0(1+cos(2πdy/λD))，条纹不变、亮纹加倍。
【真题 + 自算】与手写答案册第 2 页一致（答案册写 "I = I1+I2 = 4I0"）
2025-二-3n = 2.35 单层膜镀在 n = 1.6 玻璃上：最大/最小反射率及对应膜厚
在折射率 n = 1.6 的光学玻璃基底上镀膜层 n = 2.35，要求对波长为 500 nm 的光在正入射时给出最小反射率，试求：最大最小反射率以及对应膜层厚度为多少？

h = 500 nm4×2.35 = 53.2 nm

Rmin = 1 − 1.61 + 1.62 = (0.2308)2 = 0.053　，　h = 500 nm2×2.35 = 106.4 nm

2025-三-2什么是光学系统的像差；畸变的定义与形成原理
光学系统的像差是影响光学系统成像质量的一个关键因素，试问什么是光学系统的像差？畸变的定义和形成原理。
1像差：实际光学系统只能在近轴区完善成像；当光束孔径（孔径光阑）或视场超出近轴范围时，实际光路偏离理想（高斯）光路，使像的位置、大小、形状、颜色与理想像不一致 —— 这种成像缺陷统称像差。
2分类（背这棵树的框架）：
单色像差：球差、彗差、像散、场曲、畸变
色差：位置色差（轴向）、倍率色差（垂轴）
与孔径 h、视场 y 的关系：球差 ∝ h2；彗差 ∝ y h2；像散/场曲 ∝ y2h2；畸变 ∝ y3
3畸变：主光线与高斯像面的交点高度 不等于理想像高，使像相对于物失去相似性（形状变形）而清晰度不受影响的缺陷。
δy′ = y′实际 − y′理想 = y′·δ，δ ∝ y2（视场的平方），与孔径无关
4形成原理：孔径光阑以外的光阑（入窗/出窗）与物面不重合时，轴外点发出的主光线经系统后仍带有球差（主光线球差），使不同视场的放大率 β 不相等（β 随视场变化）；于是像的"格子"被拉弯。
δ > 0 → 正畸变（枕形，四角外伸）；δ < 0 → 负畸变（桶形，四边外鼓）
像差＝实际光路与理想光路的差别造成的成像缺陷；畸变＝主光线球差使放大率随视场变化、像失去相似性（只变形不模糊），正畸变枕形、负畸变桶形。

2026-应-1投影仪器为什么能消除渐晕题面仅一句
（回忆原文）投影仪器为什么能消除渐晕
复原猜测：请说明投影（放映）仪器的照明系统为什么能消除像面渐晕，并指出消除渐晕的条件。
1渐晕是什么：轴外点发出的、充满孔径光阑的光束，在通过系统时被镜框（或入窗/出窗）切割，参与成像的光束截面变小 → 像面照度从中心向边缘迅速下降，这就是渐晕。
2消除渐晕的充要条件：入射窗与物平面重合（等价地：出射窗与像平面重合）。窗与物面重合时，轴外点与轴上点发出的光束被同一个光阑限制、截面相同，不再随视场增大而被切割。
3投影仪怎么做到的：投影仪的照明系统（聚光镜 + 光源）按柯勒照明（Köhler illumination）设计 —— 把光源成像在投影物镜的孔径光阑（入瞳）处，把照明系统的出射窗成像在物平面（投影片）上。于是：
① 物面被均匀照明（光源的像充满入瞳，各点孔径相同）
② 物面上每一点都以充满入瞳的光束进入物镜 ⇒ 无切割 ⇒ 无渐晕、照度均匀
4对比记忆：临界照明把光源像成在物面上（亮但不均、易烧片）；柯勒照明把光源像成在入瞳上（均匀、无渐晕）—— 投影仪、显微镜都用柯勒。
因为投影仪用柯勒照明：光源成像在物镜入瞳、照明出射窗与物面重合 ⇒ 轴上轴外光束截面相同、不被镜框切割 ⇒ 消除渐晕。判据一句话：窗与物面重合。

复原猜测：区分介质对光的"一般（普遍）吸收"与"选择性吸收"，并各举一例。
1共同规律：朗伯定律 I = I0e−αd（α 为吸收系数，d 为厚度）。
2一般吸收（普遍吸收）：在考察的波段内 α 几乎不随波长变化，对各色光"一视同仁"地吸收 ⇒ 透射光颜色不变，只是变暗。
例：中性灰滤光片、大气对可见光的吸收（灰霾）、玻璃在可见光区的弱吸收
3选择性吸收：α 随波长剧烈变化，某些波段被强烈吸收（吸收带），其余波段透过 ⇒ 透射光呈剩余波段的颜色。
例：红玻璃只透红光、彩色滤光片、晶体的本征吸收带（如半导体在带隙附近的本征吸收）、叶绿素吸收红光蓝光而呈绿色
4两者关系：任何介质都不可能"只选择"或"只一般"——通常一个波段内以选择性吸收为主（特征吸收带），带外表现为一般吸收；这也是"物体有颜色"的根本原因（吸收 + 反射的选择性）。
一般吸收：α 与 λ 无关、只变暗不变色（中性滤光片）；选择性吸收：α 随 λ 剧变、透射光带颜色（彩色玻璃/晶体吸收带）；定量都用 I = I0e−αd。

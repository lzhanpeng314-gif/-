这一章只有 3 个公式在反复用：分辨角、光栅方程、光栅分辨本领。剩下全是"缺级"和"斜入射"两个变体。 把下面 9 道做完，衍射就算通了。
圆孔衍射分辨角
θmin = 1.22λD
D 是通光孔径。望远镜看 D，显微镜看 n·sin u（数值孔径）。
光栅方程（正入射）
d sinθ = kλ　(k=0,±1,±2…)
斜入射改成 d(sinθ ± sinφ) = kλ，+ 与入射光同侧。
缺级条件
da = kk′
k′ 是单缝第几级极小。d/a = 3 ⇒ 第 ±3、±6、±9 级全缺。
光栅分辨本领
R = λδλ = kN
N 是照亮的总条数 = 每毫米条数 × 光栅宽度。半角宽 Δθ = λ/(Nd cosθ)。

A · 双缝夫琅和费衍射1 题

2023-二-3单缝中央极大内有多少干涉极大；零级与一级强度
夫朗和费双缝衍射中，双缝间距 0.178 mm，缝宽 0.0445 mm。透镜的焦距 f = 50 cm，用波长为 532 nm 的平行光垂直照射双缝衍射屏，求：
（1）其衍射图样在单缝衍射中央极大值两侧的两个衍射极小值间，将出现多少个干涉极大值？
（2）零级主极大及第一级亮纹的强度是多少？（该单缝在观察屏中心点的强度为 I0）

（1）

1单缝第一极小：a sinθ1 = λ；干涉极大：d sinθ = kλ。两者的级数比就是 d/a
da = 0.1780.0445 = 4
2即第 ±4 级正好落在第一极小上 —— 缺级。所以中央极大内可见 k = 0、±1、±2、±3
共 1 + 3×2 = 7 个干涉极大

（2）

3双缝强度公式
I = 4I0 sinuu2 cos2δ2，　u = πa sinθλ = πadk
4零级：u=0、cos 项=1
I0级 = 4I0
5一级：u = π/4，(sin u/u)² = (0.7071/0.7854)² = 0.8105，cos 项 = 1
I1级 = 4I0 × 0.8105 ≈ 3.24I0
中央极大内 7 个干涉极大；零级 4I0，一级 ≈ 3.24I0（约为零级的 81%）。

B · 分辨本领3 题

人眼、望远镜、显微镜全用同一个 1.22λ/D，区别只在"D 是什么"和"要换算成什么"。
2018-二-3宇航员在 100 km 高空能分辨多远的两点
若人造卫星上的宇航员恰好能分辨离他 100 km 地面上的两个点光源，则这两个点光源的距离为多大？假设光波的波长为 550 nm，宇航员的瞳孔直径为 4 mm。
1最小分辨角
θmin = 1.22λD = 1.22 × 550×10−94×10−3 = 1.68×10−4 rad
2换算成地面距离
s = L·θmin = 100×103 × 1.68×10−4 ≈ 16.8 m
两点距离约 16.8 m —— 所以从太空肉眼是分不清汽车和楼房细节的。

C · 光栅5 题

五道题的骨架完全一样：先由"缺级"定 a 或 d，再由 N = 宽度/d 算 R 和半角宽，最后用 kmax = d/λ 数级数。
2020-二-3缝宽、二级可分辨波长差、二级半角宽度
一光栅宽为 5 cm，每毫米内有 500 条刻线。当用波长为 500 nm 的平行光垂直照射时，其第 3 级衍射光谱处在单缝衍射第一极小位置。试求：光栅每个缝的宽度；光栅第二级可分辨的最小波长差；光栅第二级衍射光谱的半角宽度。
1光栅常数与缝宽：第 3 级缺级 ⇒ d/a = 3
d = 1500 mm = 2 μm，　a = d3 ≈ 0.667 μm
2总缝数 N = 500 条/mm × 50 mm = 25000
δλ = λkN = 500 nm2×25000 = 0.01 nm
3二级衍射角：sinθ = 2λ/d = 1.0/2 = 0.5 ⇒ θ = 30°，cosθ = 0.866
Δθ = λNd cosθ = 500×10−925000×2×10−6×0.866 ≈ 1.15×10−5 rad
缝宽 0.667 μm；二级最小波长差 0.01 nm；二级半角宽度 1.15×10−5 rad。

2018-二-4垂直入射能看多少条；30° 斜入射两侧最高级次
单色平行光的波长为 λ = 490 nm，透光缝的宽度 a = 1.0×10−4 cm，不透光缝的宽度 b = 2.0×10−4 cm。（1）若单色光垂直照射在光栅上，最多能观察到的明纹总数（包括中央明纹）为多少？（2）若入射的单色光与光栅平面法线方向的夹角 φ = 30°，此时光栅衍射条纹中两侧的最高级次分别为哪一级？
1d = a + b = 3.0×10−4 cm = 3.0×10−6 m；d/a = 3
2（1）最高级次
kmax = dλ = 3.0×10−6490×10−9 = 6.1　⇒　k = 6

缺级 d/a = 3 ⇒ ±3、±6 缺。可见 0、±1、±2、±4、±5

共 1 + 4×2 = 9 条
3（2）斜入射 φ=30°，sinφ=0.5，用 d(sinθ ± sinφ) = kλ
同侧：k = d(1 + sinφ)λ = 3.0×10−6×1.5490×10−9 = 9.18　⇒　k ≤ 9
异侧：k = d(1 − sinφ)λ = 3.0×10−6×0.5490×10−9 = 3.06　⇒　k ≤ 3
4扣掉缺级：同侧 9 缺 → 最高 8 级；异侧 3 缺 → 最高 2 级
垂直入射 9 条；斜入射两侧最高分别为 +8 级 与 −2 级（9 级和 3 级都是缺级）。
易错：斜入射时"最高级次"要先按 sinθ=1 求上限，再扣掉缺级。直接写 9 和 3 会被扣分 —— 那两级恰好缺掉。

A · 一块晶片 + 光栅1 题

这题的前两问其实不考光栅，考的是"光沿光轴走有没有双折射"；第三问才回到光栅的分辨本领。
2023-二-4可见光穿过光轴切割晶片后有无变化；一级光谱角范围；能否分辨钠双线
Q 为垂直光轴切割、表面平行的单轴晶片，R 是一块刻痕密度为 500 条/mm，有效宽度为 50 mm 的衍射光栅。问：
（1）垂直入射的平行可见光（380–780 nm）通过 Q 后，是否有变化，为什么？
（2）该入射的平行光通过 Q 后，由 R 出射后的一级光谱散开的角范围（用反三角表示）。
（3）钠原子的 D 线包含波长分别为 589.6 nm，589.0 nm 两条谱线，能否用此光栅的一级光谱分辨率？

（1）

1Q 是"垂直光轴切割"的平行平板 ⇒ 光轴就是通光面的法线；光又垂直入射，所以光沿光轴传播。沿光轴传播时 o 光与 e 光速度相同（都取 n0），不存在双折射、也不发生双折射分束。
2结论：出射光在传播方向、偏振态上都没有变化（只是整体多了一段光程；可见光波段晶片透明，强度也基本不变，可忽略反射损失）。

（2）

3光栅常数
d = 1500 mm = 2.00×10−6 m = 2 μm
4一级光谱：sinθ = λ/d，两端波长各对应一个衍射角
λ = 380 nm：sinθ1 = 3802000 = 0.190 ⇒ θ1 = arcsin 0.190 = 10.95°
λ = 780 nm：sinθ2 = 7802000 = 0.390 ⇒ θ2 = arcsin 0.390 = 22.95°
角范围 = arcsin 0.190 ～ arcsin 0.390，宽度 Δθ ≈ 12.0°

（3）

5光栅一级的分辨本领
R = kN = 1 × (500 条/mm × 50 mm) = 2.5×104
6分辨钠双线所需的分辨本领（取平均波长 589.3 nm，Δλ = 0.6 nm）
R需 = λΔλ = 589.30.6 ≈ 982

2.5×104 ≫ 982 ⇒ 能分辨（余量 25 倍）。

（1）没有变化 —— 光沿光轴传播，无双折射；（2）一级光谱角范围 arcsin0.190 ～ arcsin0.390（≈10.95°～22.95°，宽 12.0°）；（3）能分辨，R = 2.5×104 ≫ 所需 982。

B · 设计光栅1 题

"设计"题就是把四个条件翻译成四个不等式，取等号即可。这题的答案正好是 2017-二-3 的题给条件（d = 2.4 μm、a = 0.8 μm、宽 36 mm）。
2016-二-3设计光栅：二级 θ≤30°、色散尽量大、三级缺级、二级分辨率 0.02 nm
设计一块光栅，要求使波长 λ = 600 nm 的第二级谱线的衍射角 θ ≤ 30°，色散尽可能大，第三级谱线缺级，对于波长 λ = 600 nm 的二级谱线能分辨 0.02 nm 的波长差。
1条件一（二级 θ ≤ 30°）：由光栅方程 d sinθ = 2λ
d ≥ 2λsin30° = 2 × 6000.5 nm = 2400 nm = 2.4 μm
2条件二（色散尽量大）：角色散 dθdλ = kd cosθ 随 d 减小而增大 ⇒ 取 d 的下限
d = 2.4 μm（此时二级恰为 30°）
3条件三（三级缺级）：缺级条件是 da = kk′，三级（k = 3）对应单缝第一极小（k′ = 1）
da = 3 ⇒ a = 2.43 = 0.8 μm
4条件四（二级能分辨 0.02 nm）：R = kN = 2N ≥ λΔλ
N ≥ 12 · 6000.02 = 15000 条
5换算成几何尺寸：总宽度 W = Nd，刻线密度
W = 15000 × 2.4 μm = 36 mm，　1d = 12.4 μm ≈ 417 条/mm
设计结果：光栅常数 d = 2.4 μm（≈417 条/mm），缝宽 a = 0.8 μm，刻线总数 N ≥ 15000（光栅有效宽度 ≥ 36 mm）。此时二级衍射角正好 30°，三级缺级，二级分辨本领 R = 3×104，可分辨 0.02 nm。
自检：把答案代回 2017-二-3（"总宽度 36 mm、缝宽 0.8 μm、三级落在单缝第一极小、λ = 600 nm"）—— 该题算出的 d = 2.4 μm、N = 15000、零级半角宽 1.67×10−5 rad，与本页结果完全自洽，说明这道"设计题"就是按 2017 那组参数出的。

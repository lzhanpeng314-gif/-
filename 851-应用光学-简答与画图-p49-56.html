A · 完善像与完善成像条件7 条

七年里问了六次。核心只有一句：物点发出的所有光线到像点的光程相等；轴外点再加正弦条件。
2017-三-2什么是完善像？系统成完善的条件？
什么是光学系统的完善像，光学系统成完善的条件是什么？

完善像：由同一物点发出的所有光线，经系统后都交于同一点（点对点成像），像面上得到清晰的点像，称该像点为物点的完善像。等价说法：系统把发散的球面波变换成会聚的球面波。

成完善像的条件：

  • 等光程（费马原理）：物点到像点的任意两条光路，光程相等；
  • 正弦条件：轴外点还要满足 n y sinu = n′y′ sinu′，否则宽光束有彗差。
背：完善像 = 点对点 + 等光程；轴外点再加正弦条件。
【真题 + 教材】
2018-三-1（前）完善成像条件
光学系统的完善的成像条件是什么？

物点与像点之间所有光线的光程相等（等光程条件），即实际波面为以像点为中心的球面；对轴外点还要满足正弦条件，保证宽光束无彗差。同时满足这两条的系统称为理想光学系统。

背：等光程 + 正弦条件。
【真题 + 教材】
2019-三-1完善条件；无穷远物点经单一曲面反射成完善像的面形
光学系统成完善像的条件是什么？试由该条件确定将无穷远的物点经单一曲面反射成完善实像点的曲面形状。

条件：等光程（轴外点再加正弦条件）。

面形：旋转抛物面。平行光（无穷远物点）沿轴入射，反射后会聚于焦点，焦点就是像点；抛物面上任一点到焦点的距离等于它到准平面的距离，故各条光路光程相等 —— 满足等光程，成完善像。

背：无穷远物点 → 抛物面（焦点即像点）；有限共轭点 → 椭球面（两焦点为物、像点）。
【真题 + 教材】
2020-三-2（前）完善成像条件
光学系统的完善成像条件是什么？

同一物点发出的所有光线经系统后光程相等并交于同一点；轴外点还需正弦条件 n y sinu = n′y′ sinu′。

背：等光程（轴上）+ 正弦条件（轴外）。
【真题 + 教材】
2021-三-1格里高利望远镜次镜应是什么面形
什么是光学系统的完善像？格里高利双反射式望远镜的次镜为了将主镜在有限位置的实像（对次镜为实物）进一步成像为有限处的实像，它的次镜反射面的几何面应该是什么形状，并说明原因？

完善像：同一物点发出的所有光线经系统后交于同一点。

次镜面形：旋转椭球面（凹面）。椭球的两个焦点分别与被成像的物点（主镜所成的实像点）和最终像点重合。

原因：次镜要把有限距离的实物点成实像于另一有限距离处，等光程要求 |AP| + |PA′| = 常数；到两定点距离之和为常数的曲面正是以这两点为焦点的旋转椭球面。

背：主镜抛物面（无穷远→焦点），次镜椭球面（焦点对焦点）；两个焦点就是物点与像点。
【真题 + 教材】

2024-三-1完善像条件；单个球面反射镜能否完善成像
成完善像的条件？单个球面反射镜能否成完善像？

条件：等光程 +（轴外）正弦条件。

单个球面反射镜：一般不能 —— 球面对有限共轭点有球差（只有近轴小光束才近似完善）。能完善成像的只有特殊共轭位置：

  • 物点在球心 C：所有光线沿半径入射、原路返回，像也在 C；
  • 物点在镜面顶点：像与物重合于顶点（平凡情形）。

要在有限共轭距下真正完善成像，面形须是椭球面（两焦点为物、像点）；物在无穷远时须是抛物面。

背：球面镜只有“物在球心”“物在顶点”两处完善，其余有球差。

B · 几何像差与色差5 条

单色像差 5 种、色差 2 种，必须能一口气报出来；畸变、像散、场曲要能对上图。
2018-三-1（后）像差概念；几何像差包括哪几种
解释实际光学系统的像差概念？光学系统的几何像差主要包括哪几种？

像差：实际光学系统所成的像与理想（高斯）像之间的偏差。本质是实际出射波面偏离了理想的球面波。

几何像差：

  • 单色像差 5 种：球差、彗差、像散、场曲、畸变；
  • 色差 2 种：位置色差（轴向色差）、倍率色差（垂轴色差）。
背：单色五种“球彗像场畸”，色差两种“位置、倍率”。
【真题 + 教材】
2020-三-2（后）色差有哪几种、产生原因
光学系统的色差主要包括哪几种，解释其产生的原因？

位置色差（轴向色差）：轴上物点不同波长的光成像位置不同（焦距随波长变），像点沿光轴前后分开，屏上看到彩色圆斑。

倍率色差（垂轴色差）：不同波长的垂轴放大率不同，同一物高的像高不同，像的边缘出现彩色镶边。

原因：光学材料折射率随波长变化（色散），n 随 λ 减小而增大，使不同色光的焦距和放大率不同。

背：色差 = 色散引起；位置色差沿轴、倍率色差垂轴。
【真题 + 教材】
2021-三-2由图判断 (a)(b) 各存在哪种单色像差
什么是光学系统的像差？下图 (a) 和 (b) 分别给出了物体经过两个光学系统成像后像面，试问这时它们各自主要存在哪种单色像差？

像差：实际像与理想像的偏差（实际波面偏离理想球面波）。

(a) 畸变：正方形像四边内凹、四角外伸，放大率随视场增大 —— 是正（枕形）畸变。像本身仍清晰，只是形状变了（物像不相似）。

(b) 像散：同心圆（切向）与辐射线（弧矢）属于子午、弧矢两个方向，两者不能同时清晰，说明子午像与弧矢像不重合 —— 典型像散（通常伴随场曲）。

答：(a) 畸变（枕形）；(b) 像散。【待核】：(b) 的扫描图样较粗，若答案册判为“场曲”，以教材图为准 —— 像散与场曲在轴上点之外的图上常同时出现，但“两个方向不能同时清晰”这一特征是像散。
【真题 + 教材】
2023-三-1畸变的定义与形成原因（画图说明）
从物像关系画图说明什么是光学成像的畸变像差，并解释其形成原因。

定义：同一物平面内，不同视场的垂轴放大率不同，使像与物不相似（直线变弯），但每个像点仍清晰。定量：主光线与高斯像面的交点高度 y′ 不等于理想像高 y0′，畸变 Δy′ = y′ − y0′。

原因：孔径光阑（入瞳）不在透镜上时，不同视场的主光线通过透镜的不同部位；透镜各带的球差/焦距不同，等效放大率随视场变化 → 像的径向位置被拉大或压缩。

两种：正畸变（枕形，β 随视场增大，四角外伸）；负畸变（桶形，β 随视场减小，四边外鼓）。

背：畸变 = 放大率随视场变 → 物像不相似但清晰；正枕形、负桶形；光阑位置是主因。
【真题 + 教材】
2024-三-2像散、场曲的概念及对成像的影响
两个像散，场曲的概念，对成像又有何影响？

像散：轴外物点发出的细光束经系统后，子午方向与弧矢方向的聚焦位置不同，形成两条互相垂直的短焦线（子午焦线、弧矢焦线），两线之间为最小弥散圆。影响：轴外点不能成清晰的点像，像被拉成椭圆或短线，视场越大越明显。

场曲：即使没有像散，平面物体的像面也不是平面而是曲面（子午场曲、弧矢场曲，两者一般不重合）。影响：用平面探测器接收时，中心调焦清晰则边缘离焦模糊，反之亦然，有效视场受限。

背：像散 = 子午/弧矢焦线分离；场曲 = 像面是弯的；两者都使轴外像质下降，且常同时出现。

C · 孔径光阑与视场光阑1 条

2018-三-2孔径光阑与入瞳/出瞳；视场光阑与入窗/出窗
对于一个光学系统，什么是孔径光阑，它与入瞳和出瞳的关系是什么？什么是视场光阑，它与入窗和出窗的关系是什么？

孔径光阑：系统中限制轴上物点成像光束孔径角（光束立体角）的那个光阑，它决定进入系统的光能量和系统的分辨率。

  • 入瞳：孔径光阑经它前方光组所成的像，是物方孔径角的入口；
  • 出瞳：孔径光阑经它后方光组所成的像，是像方孔径角的出口；
  • 三者互为共轭；入瞳对轴上物点的张角即物方孔径角。

视场光阑：限制物平面（或像平面）上成像范围的光阑，决定视场大小。

  • 入窗：视场光阑经前方光组所成的像；
  • 出窗：视场光阑经后方光组所成的像；
  • 入窗对入瞳中心的张角 = 物方视场角；出窗对出瞳中心的张角 = 像方视场角；过入瞳中心的光线叫主光线。
背：光阑→入瞳/出瞳（前/后成像），视场光阑→入窗/出窗；入瞳定孔径，入窗定视场。

D · 光度学：光亮度与光照度1 条

2017-三-3光亮度和光照度的定义与表达式
什么是光亮度和光照度？并写出它们定义的数学表达式。

光亮度 L：发光面上一点在给定方向上的发光强度 dI，与该面元在垂直于该方向的投影面积 dA cosθ 之比。

L = dIdA cosθ　（cd/m2）

光照度 E：照射到面元上的光通量 dΦ 与该面元面积 dA 之比。

E = dΦdA　（lx）

配套的两个量：发光强度 I = dΦ/dΩ（cd），光通量 Φ（lm）。

背：亮度 = 单位投影面积上的发光强度（cd/m²）；照度 = 单位面积上的光通量（lx）。

E · 费马原理1 条

2019-三-2费马原理的内容；用它解释直线传播
费马原理的内容是什么？试用该原理解释光在均匀各向同性的介质中沿直线传播。

内容：光从一点传播到另一点，其实际路径使光程取极值（极小、极大或稳定值），即光程的一阶变分为零：

δ∫AB n ds = 0

解释直线传播：均匀各向同性介质中 n = 常数，光程 = n × 几何路程；两点间几何路程以直线最短，故光程也最小，光沿直线传播。

背：费马 = 光程取极值（δ∫n ds = 0）；均匀介质 n 为常数 → 直线最短 → 直线传播。

F · 景深1 条

2019-三-3景深定义、影响因素；增大景深怎么调光圈
什么是光学系统的景深？景深的大小受哪些因素影响？照相时为了增加景深，光圈应该增大还是减小？

景深：在像面上能成清晰像的物空间深度（= 远景深度 + 近景深度），即物平面前后能清晰成像的范围。景深端点对应弥散圆直径等于允许值。

影响因素：

  • 光圈（相对孔径）：越小（F 数越大）景深越大；
  • 焦距：越短景深越大；
  • 摄距：越远景深越大；
  • 允许弥散圆：越大景深越大。

增加景深：缩小光圈（增大 F 数）。

背：景深 ∝ 1/光圈、∝ 1/焦距²、∝ 摄距²；要景深就收小光圈。

G · 屋脊棱镜1 条

2019-三-4什么是屋脊棱镜；举例并画平面表示图
什么是屋脊棱镜？试列举一个屋脊棱镜，并给出平面表示图。

定义：把直角棱镜的一个反射面（通常是斜面）做成 90° 屋脊（两个互相垂直的反射面）的棱镜。屋脊的两个面各反射一次（共两次），使像在垂直于屋脊的方向上倒转，常用于望远系统/双筒望远镜的倒像。

举例：屋脊直角棱镜（阿贝棱镜）、屋脊五角棱镜、屋脊半五角棱镜。

平面表示图画法（答题时按这四步画）：

  1. 画直角棱镜的三角形轮廓（直角在左上，斜边朝右下）；
  2. 把斜边改画成“人”字形折线（两条 45° 线交于屋脊棱），在棱上标 90°；
  3. 画出光线：从前表面入射 → 在屋脊两面各反射一次 → 从另一表面出射；
  4. 用箭头标出出射方向相对入射方向折转 180°（反向），像上下颠倒。
背：屋脊棱镜 = 斜面做成 90° 双反射面的棱镜；两次反射、像沿垂直屋脊方向倒转；例：屋脊直角棱镜。

H · 显微镜1 条

2020-三-1显微镜的结构、放大原理与分辨率
阐述显微镜光学系统结构组成和成像放大原理；显微镜分辨率受哪些物理参量影响？

组成：物镜 + 目镜（外加聚光镜、光源、载物台）。

放大原理：物体放在物镜前焦点外不远处，物镜先成放大实像于目镜前焦面附近；目镜再把该实像放大成虚像（正常调节时在无穷远，或成在明视距离）供人眼观察。两次放大：

Γ = β物 · Γ目 = (−Δf′物) · 250 mmf′目

其中 Δ 为光学筒长（物镜后焦点到目镜前焦点的距离）。

分辨率：受物镜数值孔径 NA = n sinu 与波长限制，

δ = 0.61λNA

影响因素：波长 λ（越短越好）、介质折射率 n、孔径角 u（NA 越大越好），以及照明方式与像差校正水平。

背：物镜成实像、目镜再放大；Γ = β物·250/f′目；分辨率 δ = 0.61λ/(n sin u)。

I · 放大镜与视角放大率1 条

2023-三-2放大镜视角放大率；5× 的焦距
什么是放大镜的视角放大率？放大倍数 5× 的放大镜焦距多少？

定义：视角放大率 = 用仪器后像对人眼的张角 ω′，与不用仪器、把物放在明视距离（250 mm）处时对人眼的张角 ω 之比：Γ = tanω′/tanω。

放大镜把物放在前焦点内、像成在无穷远（正常调节）时：Γ = 250 mm/f′。

f′ = 2505 = 50 mm
答：f′ = 50 mm（按像在无穷远）；若约定像成在明视距离，则 Γ = 1 + 250/f′，f′ = 62.5 mm。

J · 图解法：物像作图11 条

作图题只考三件事：三条特殊光线、主面等高、虚物/负光组的符号。先把“总则”背下来，后面 11 道都是套它。

作图总则（先背这段）

  • 三条特殊光线：① 平行于光轴的入射光线，出射后过（或其反向延长线过）像方焦点 F′；② 过物方焦点 F 的光线，出射后平行于光轴；③ 过节点 J 的光线，出射后方向不变（两侧为空气时 J = H）。
  • 主面性质：物方主面 H 与像方主面 H′ 上等高的两点共轭（β = +1）；F 到 H 为 f，H′ 到 F′ 为 f′。
  • 轴上点：像是轴上点，取一条轴外辅助光线（例如过 F 作与它平行的辅助线），定出出射方向，与光轴的交点即像点。

K · 棱镜系统的像方坐标系5 条

判两件事：反射次数定手性（奇数次 → 左手系；偶数次 → 右手系），镜面走向定坐标轴翻转。所有反射面法线都在同一平面内时，看光轴转了多少。

判定规则（先背）

  • 一次反射：垂直于镜面的那个坐标分量反向，手性改变（右手 → 左手）。
  • 奇数次反射 → 左手系（镜像）；偶数次 → 右手系。
  • 平行双镜（潜望镜）：出射光轴与入射同向，坐标系不变。
  • 垂直双镜（角反射器）：出射光轴反向，沿两个镜面法线方向的两个轴都反向，第三轴不变。
  • 反射面共面、且出射光轴与入射同向（偶数次）⇒ 三个轴都与物方同向。
2017-三-6平面镜 + 等腰直角棱镜（两反射面互垂）
已知物空间的右手坐标系 o-xyz，oz 为光轴方向，作平面镜与一个等腰直角棱镜构成系统的像方坐标系 o′-X′Y′Z′。

光路：光沿 +z 进入棱镜 → 在“/”斜面全反射，折向 +y（向上）→ 出射后打在“\”平面镜上 → 再反射，折回 −z（向左）。

反射次数：2 次 → 手性不变，仍为右手系。

坐标轴：两个镜面法线都在 yz 平面内，x 轴不变；两次反射把 z、y 各反一次：

X′ = x，　Y′ = −y，　Z′ = −z

即出射光轴与入射反向，像上下、前后都反，左右不变（角反射器效果）。

答：出射沿 −z；X′ = x、Y′ = −y、Z′ = −z；两次反射，右手系。

旋向判定标准（记住这一条就够）　第一步·定轴：让光朝你射来（观察者迎着光），取向右为 x、向上为 y，此时 x × y 恰指向你。δ 只能用这两个轴算：δ = φ上 − φ右。轴名取错，结论必反。　第二步·判据：0 < δ < π → 右旋（E 顺时针）；−π < δ < 0 → 左旋（逆时针）。速记 +90° → 右旋，−90° → 左旋。　为什么老乱：① 有些书写"沿传播方向看"，结论整体反过来；② 复数式 Ey/Ex = e±iπ/2 的正负取决于时间因子取 eiωt 还是 e−iωt，各书不一，别背 ±i；③ 最要命的是轴名——同一束光，x、y 换个叫法，δ 就变号。　零风险判法：写出 E右 = A cos(ωt)、E上 = A cos(ωt + δ)，代 ωt = 0° 与 30° 各画一个箭头，顺时针即右旋。不用记任何符号。

把下面 9 道吃透，这一章就封顶了。
布儒斯特角
θB = arctann2n1
此角入射时 rp=0，反射光只剩 s 分量，完全偏振。
s 分量反射系数
rs = −sin(θi − θt)sin(θi + θt)
永远为负 —— 反射时 s 分量必反相（半波损失）。
p 分量反射系数
rp = tan(θi − θt)tan(θi + θt)
θi+θt=90° 时 tan 趋于无穷 ⇒ rp=0，就是布儒斯特角。
正入射反射率
R = n2 − n1n2 + n12
n=1.5 时 R=4%。注意 R=r²，别把 r=0.2 当成光强比。
透射系数 ts、tp
ts = 2n1cosθ1n1cosθ1 + n2cosθ2　，　tp = 2n1cosθ1n2cosθ1 + n1cosθ2
两个 t 都恒正（透射不改变振动方向的符号）。透射率 T = (n2cosθ2/n1cosθ1)·t²，不是 t²——漏这个因子是本章最常见的扣分点。
自然光 / 任意线偏振的反射率
自然光：R = Rs + Rp2　；　线偏振（振动面与入射面夹角 α）：R = Rssin2α + Rpcos2α
α=90°（只有 s）⇒ R=Rs；α=0（只有 p）⇒ R=Rp，且 θB 时 R=0。自然光是两个分量的平均，不是随便取一个。
本章大点 · 看到问什么，就选哪个公式
题目问的是先做什么用哪个式子
反射率 / 透射率折射定律求 θ2菲涅尔 rs、rp，再 R=r²
布儒斯特角直接套tanθB = n2/n1
正入射不用分 s、pr = (n2−n1)/(n2+n1)
全反射 / 临界角确认 n1>n2sinθc = n2/n1
偏振度 / 振动方向两个 r 都要算比值定方位角，P 用 I 的差和
  • 一句话：先折射定律定角度，再菲涅尔定振幅，最后看 rs 与 rp 是否反号——反号就说明振动方向相对入射面翻转了。

按入射光偏振态选式（最容易混的一层）

任意偏振 + 全反射Rs=Rp=1线偏振→椭圆（相移差 δp−δs）；自然光→仍自然光
  • 四句判据：①只问 R ⇒ 自然光取平均、线偏振按 sin²α/cos²α 加权；②问反射光偏振态 ⇒ 先看 rs、rp 有没有一个为 0（θB 或正入射）；③问振动方向 ⇒ 用 tanα′ 且带符号，符号取决于 rs、rp 是否异号；④问全反射 ⇒ 先比 n1、n2 再算 θc。
  • 易错三连：把 r 当光强比（R=r²）；T 漏 (n2cosθ2/n1cosθ1)；自然光的 R 只算了 Rs。

一 · 光波场表达式与空间频率1 题 · 考纲点名

① 空间频率
  • λ = c/ν；空间频率是矢量，方向沿波矢
  • 由相位分布反推：沿某方向相位每增 2π，前进一个 λ
k = 2πλ = 2πf　，　k = ∇φ
考纲原文写的是"空间频率计算"—— 这是第一章唯一必考的概念型计算题。
A · 全反射的相位差 + 反射后偏振旋向（851 必考型）
tanδs2 = −√(sin²θ1 − n²)cosθ1　，　tanδp2 = −√(sin²θ1 − n²)n²cosθ1（n = n2/n1 < 1）
  • 总相位差 Δφ = δp − δs（全反射时 δs、δp 都是负的，Δφ ≠ 0 ⇒ 线偏振入射必变椭圆偏振）。
  • 何时成圆：入射光振动方向与入射面成 45°（两分量等幅）且 Δφ = 90°，两者同时满足才行。
  • 旋向判据（最快的判法）：看 rs·rp 的符号——同号 ⇒ 旋向不反转；异号 ⇒ 旋向反转。（全反射时可等价看 δp−δs 是否跨过 0/±180°。）
  • 常规入射（部分反射）：rs = −sin(θ1−θ2)/sin(θ1+θ2)、rp = tan(θ1−θ2)/tan(θ1+θ2)；布儒斯特角 tanθB = n2/n1 ⇒ rp = 0，反射光全偏振（s 分量），透射光部分偏振。
  • 透射偏振度：P = |Tp−Ts|/(Tp+Ts)，别写成 100%（反射全偏振 ≠ 透射全偏振）。

二 · 布儒斯特角与偏振度3 题

② 布儒斯特角
  • 反射光为纯 s（振动 ⊥ 入射面），且反射光 ⊥ 折射光
  • 光疏→光密用 n₂/n₁，反过来取倒数
tanθB = n2n1
P = Imax−IminImax+Imin
套路固定：先算 θB = arctan(n2/n1) → 再算 rs（此时 rp = 0）→ 用 Ip、Is 各占一半求偏振度。
2017-二-1红宝石表面反射光为全偏振光，求入射角、透射光强与偏振度
一束自然光由空气经红宝石（n = 1.76）的表面反射，若检测其反射光为全偏振光，则入射角应为多少？求此入射角入射条件下，透射光的强度和偏振度。
1反射光全偏振 ⇒ 入射角为布儒斯特角
θB = arctan 1.76 ≈ 60.4°，　θt = 90° − θB = 29.6°
2此时 rp = 0，只需算 rs（θi+θt = 90°，sin = 1）
rs = −sin(θi−θt) = −sin 30.8° = −0.512　⇒　Rs = 0.262
3自然光两分量各占一半，分别过界面
分量入射光强反射率 R透射率 T = 1−R透射光强
p0.5 I0010.5 I0
s0.5 I00.2620.7380.369 I0
4求偏振度
P = (Ip − Is)/(Ip + Is) = (0.5 − 0.369)/(0.5 + 0.369) ≈ 0.151
入射角 60.4°（= arctan 1.76）｜反射光强 0.131 I0｜透射光强 0.869 I0｜透射光偏振度 ≈ 15%

⚠ 别把偏振度算成 100%：反射光完全偏振，但**透射光只是"部分偏振"**，它的 s 分量被反射走了一小部分而已。

三 · 菲涅尔公式、反射率与振动方向3 题

③ 菲涅尔公式
  • s 用 sin、p 用 tan
  • n₁<n₂ 时 rs<0、rp>0 反号 ⇒ 振动方向翻转
rs = −sin(θ1−θ2)sin(θ1+θ2)　，　rp = tan(θ1−θ2)tan(θ1+θ2)
R = r2　，　T = 1 − R
s、p 的差别只来自边界条件的投影：s 振动平行界面，直接用 sin；p 要投影到界面上，多出一个 cos，所以公式里出现 tan。
同一道题连考三次（2009 / 2022 / 2024 只改了折射率），必考。

1折射角
sin θt = sin30°/1.52 = 0.3289　⇒　θt = 19.20°
2上表面菲涅尔系数
rs = −sin(10.80°)sin(49.20°) = −0.2476　⇒　Rs = 6.13%
rp = tan(10.80°)tan(49.20°) = +0.1647　⇒　Rp = 2.71%
3振动面与入射面成 45° ⇒ 两分量等幅
R = (Rs + Rp)/2 = 4.42%
4上表面反射光振动方向
tan α1 = rs/rp = −1.503　⇒　α1 ≈ −56.4°

即与入射面成 56.4°，偏向 s 一侧（另一侧）。

四 · 正入射与全反射2 题

④ 正入射与全反射
  • 正入射无偏振之分，s、p 反射率相同
  • 全反射仍有倏逝波；s、p 相位跃变不同
r = n2−n1n2+n1
sinθc = n2n1
正入射只有三个公式：r = (n2−n1)/(n2+n1)、R = r²、rp 与 rs 反号（圆偏振旋向反转）。
2020-二-1左旋圆偏振光正入射，求反射光偏振态与光强
迎着光传播方向观察，一束左旋圆偏振光的光强为 I0，由空气垂直入射到折射率为 1.5 的玻璃上，求反射光的偏振态和光强。
1正入射反射系数
r = (n2−n1)/(n2+n1) = (1.5−1)/(1.5+1) = 0.2
2反射率
R = r² = 0.04　⇒　Ir = 0.04 I0
3偏振态：正入射时 rp = −rs，两分量都反号但相对相位差增加 π，圆偏振的旋向反转
左旋 → 右旋圆偏振光
反射光为右旋圆偏振光，光强 0.04 I0。
易错点：① 忘记 rp、rs 反号，答"仍是左旋"；② 把光强算成 0.2 I0（那是振幅比，不是光强比）。
记忆：圆偏振光正入射反射，旋向必反转；斜入射时不一定。

2023-二-1棱镜内两次反射后反向射出，求出射光强
如图，经两侧面反射后从斜面反方向射出，入射光强 I0，求 I。
图
1光路分解：正入射进入（一次透射）→ 两个侧面各全反射一次 → 再正入射射出（一次透射）。
2全反射时若无吸收、无散射，反射率 = 1，两次全反射不损失能量（这是全反射的特点，也是它被用作反射棱镜的原因）。
3进、出两个表面都是正入射，各有一次反射损失。设棱镜折射率 n：
R = [(n−1)/(n+1)]²，　透射率 T = 1 − R
I = I0 · T · 1 · 1 · T = I0(1 − R)²
理想情形（忽略表面反射损失、全反射无损耗）：I ≈ I0。
计入两表面反射：I = I0[1 − ((n−1)/(n+1))²]²（n = 1.5 时约 0.92 I0；n = 1.52 时约 0.919 I0）。

布儒斯特角
θB = arctann2n1
此角入射时 rp=0，反射光只剩 s 分量，完全偏振。
s 分量反射系数
rs = −sin(θi − θt)sin(θi + θt)
永远为负 —— 反射时 s 分量必反相（半波损失）。
p 分量反射系数
rp = tan(θi − θt)tan(θi + θt)
θi+θt=90° 时 tan 趋于无穷 ⇒ rp=0，就是布儒斯特角。
正入射反射率
R = n2 − n1n2 + n12
n=1.5 时 R=4%。注意 R=r²，别把 r=0.2 当成光强比。

一 · 光波场表达式与空间频率1 题 · 考纲点名

考纲原文写的是"空间频率计算"—— 这是第一章唯一必考的概念型计算题。
2015-3由相位分布求电场表示式、空间频率与波矢方向考纲点名
设空气中一单色平面光波的频率为 ν = 1014 Hz，电场强度的振幅大小为 1 V/m。t = 0 时刻，在 xoy 平面（z = 0）上的相位分布如图所示，等相位线与 x 轴垂直，φ = 0 的等相位线坐标为 x = −5 μm，φ 随 x 线性增加，x 每增加 4 μm 相位增加 2π。求该光波电场强度大小的表示式、空间频率及波矢方向。
1求波长与波数
λ = c/ν = 3×108 / 1014 = 3×10−6 m = 3 μm，　k = 2π/λ = 2π/3 μm−1
2由"等相位线与 x 轴垂直"定出 ky = 0 —— 波矢在 xOz 平面内。
3由"x 每增加 4 μm 相位增加 2π"定出 kx（相位随 x 增加，故取正）
kx = 2π/4 μm = π/2 μm−1　⇒　空间频率 fx = kx/2π = 1/4 μm−1
4由 kx²+kz² = k² 求 kz（取沿 +z 传播）
kz = √(k² − kx²) = √(4π²/9 − π²/4) = π√7/6 μm−1 ≈ 1.386 μm−1
5定初相位：φ = 0 在 x = −5 μm 处，故
φ0 = −kx·(−5) = 5π/2　（≡ π/2，即 cos 变为 −sin）
电场表示式（振幅 1 V/m）：
E = cos( (π/2)x + (π√7/6)z − 2π×1014 t + 5π/2 ) V/m　（x、z 以 μm 计）
空间频率：fx = 1/4 μm−1，总空间频率 f = 1/λ = 1/3 μm−1
波矢方向：在 xOz 面内，与 z 轴夹角 θ = arccos(kz/k) = arccos(√7/4) ≈ 48.6°

二 · 布儒斯特角与偏振度3 题

套路固定：先算 θB = arctan(n2/n1) → 再算 rs（此时 rp = 0）→ 用 Ip、Is 各占一半求偏振度。
2017-二-1红宝石表面反射光为全偏振光，求入射角、透射光强与偏振度
一束自然光由空气经红宝石（n = 1.76）的表面反射，若检测其反射光为全偏振光，则入射角应为多少？求此入射角入射条件下，透射光的强度和偏振度。
1反射光全偏振 ⇒ 入射角为布儒斯特角
θB = arctan 1.76 ≈ 60.4°，　θt = 90° − θB = 29.6°
2此时 rp = 0，只需算 rs（θi+θt = 90°，sin = 1）
rs = −sin(θi−θt) = −sin 30.8° = −0.512　⇒　Rs = 0.262
3自然光两分量各占一半，分别过界面
分量入射光强反射率 R透射率 T = 1−R透射光强
p0.5 I0010.5 I0
s0.5 I00.2620.7380.369 I0
4求偏振度
P = (Ip − Is)/(Ip + Is) = (0.5 − 0.369)/(0.5 + 0.369) ≈ 0.151
入射角 60.4°（= arctan 1.76）｜反射光强 0.131 I0｜透射光强 0.869 I0｜透射光偏振度 ≈ 15%

⚠ 别把偏振度算成 100%：反射光完全偏振，但**透射光只是"部分偏振"**，它的 s 分量被反射走了一小部分而已。

2019-二-1反射光强为零时，入射光的偏振态与入射角
一束光由空气经透明玻璃平板（n = 1.56）的表面反射，若检测到反射光强为零，求这束光的偏振态和入射角。（计算结果用反三角函数表示）
1反射光强为零 ⇒ 满足布儒斯特条件，且入射光不能含 s 分量
θ = θB = arctan 1.56 ≈ 57.3°
2偏振态：线偏振光，振动方向平行于入射面（纯 p 分量）。
入射角 θ = arctan 1.56 ≈ 57.3°；入射光为振动面平行于入射面的线偏振光。

反向问法也常考：若问"反射光为全偏振光"，答案是自然光或部分偏振光（只要含 p、s，反射后只剩 s）。

【真题 + 自算】
2016-二-2玻璃片：反射率、振动方向；以布儒斯特角入射并绕轴旋转一周
光强为 I0 的线偏振光以 θi 角由空气斜入射到玻璃片 M（n = 1.50，背面涂黑）上，若入射线偏振光的振动平面与入射面的夹角为 45°，入射角 θi = 30°，求玻璃片的反射率及反射光的振动方向；若入射光以布儒斯特角 θB 入射，M 以入射光方向为轴旋转一周，试确定反射光强的变化规律及反射光的偏振度。

（1）θi = 30°，n = 1.5

1折射角
sin θt = sin30°/1.5 = 1/3　⇒　θt = 19.47°
2菲涅尔系数
rs = −sin(10.53°)sin(49.47°) = −0.240　⇒　Rs = 5.78%
rp = tan(10.53°)tan(49.47°) = +0.159　⇒　Rp = 2.53%
3振动面与入射面成 45° ⇒ Ep = Es，两分量能量各半
R = (Rs + Rp)/2 = 4.2%　（反射光强 ≈ 0.042 I0）
4反射光振动方向（用振幅比，注意 rs 为负、rp 为正 ⇒ 反相）
tan α′ = rs/rp = −0.240/0.159 = −1.512　⇒　α′ ≈ −56.5°

即反射光振动方向与入射面成 56.5°，且在入射面的另一侧（因 s 分量反相）。

（2）以布儒斯特角入射，并绕入射光轴旋转一周

5θB = arctan 1.5 = 56.31°，此时 rp = 0，反射光只剩 s 分量
rs = −sin(56.31° − 33.69°) = −sin 22.62° = −0.3846　⇒　Rs = 14.8%
6绕入射光轴旋转 ⇒ 入射面转，振动面与入射面的夹角 α 随之连续变化
Es = E0 sin α　⇒　Ir = Rs · I0 sin²α = 0.148 I0 sin²α
反射光强按 sin²α 周期变化（周期 π）：α = 90°、270° 时最强 0.148 I0；α = 0°、180° 时为零。
反射光始终是线偏振光（振动垂直于入射面），故偏振度恒为 1（100%）（消光位置无光，不参与定义）。

三 · 菲涅尔公式、反射率与振动方向3 题

同一道题连考三次（2009 / 2022 / 2024 只改了折射率），必考。
2022-三-1平行平板：上表面反射率与上下表面反射光的振动方向★3 次
一平面光波以 30° 角由空气入射到折射率为 1.52 的平行平板上，其振动平面与入射面的夹角为 45°，试求该平板上表面的反射率和平板上、下表面反射光的振动方向。
1折射角
sin θt = sin30°/1.52 = 0.3289　⇒　θt = 19.20°
2上表面菲涅尔系数
rs = −sin(10.80°)sin(49.20°) = −0.2476　⇒　Rs = 6.13%
rp = tan(10.80°)tan(49.20°) = +0.1647　⇒　Rp = 2.71%
3振动面与入射面成 45° ⇒ 两分量等幅
R = (Rs + Rp)/2 = 4.42%
4上表面反射光振动方向
tan α1 = rs/rp = −1.503　⇒　α1 ≈ −56.4°

即与入射面成 56.4°，偏向 s 一侧（另一侧）。

5下表面反射光：由斯托克斯倒逆关系 rs′ = −rs、rp′ = −rp，再乘往返透射系数 Ts = 1−Rs、Tp = 1−Rp
tan α2 = (Ts·|rs|)/(Tp·|rp|) = (0.939×0.2476)/(0.973×0.1647) ≈ −1.45　⇒　α2 ≈ −55.4°
上表面反射率 4.4%；上表面反射光振动方向与入射面成 56.4°，下表面反射光与之几乎同向（≈55.4°） —— 两者接近但不相等，差别来自两次透射对 s、p 的衰减不同。
这一问的答案不太统一：各资料对"下表面"的取值口径不同（是否计入往返透射）。考场策略：把上表面算准（4.4% / 56.4°），下表面写出"r′ = −r + 往返透射"的方法与数值即可，阅卷通常给方法分。

四 · 正入射与全反射2 题

正入射只有三个公式：r = (n2−n1)/(n2+n1)、R = r²、rp 与 rs 反号（圆偏振旋向反转）。
2020-二-1左旋圆偏振光正入射，求反射光偏振态与光强
迎着光传播方向观察，一束左旋圆偏振光的光强为 I0，由空气垂直入射到折射率为 1.5 的玻璃上，求反射光的偏振态和光强。
1正入射反射系数
r = (n2−n1)/(n2+n1) = (1.5−1)/(1.5+1) = 0.2
2反射率
R = r² = 0.04　⇒　Ir = 0.04 I0
3偏振态：正入射时 rp = −rs，两分量都反号但相对相位差增加 π，圆偏振的旋向反转
左旋 → 右旋圆偏振光
反射光为右旋圆偏振光，光强 0.04 I0。
易错点：① 忘记 rp、rs 反号，答"仍是左旋"；② 把光强算成 0.2 I0（那是振幅比，不是光强比）。
记忆：圆偏振光正入射反射，旋向必反转；斜入射时不一定。
【真题 + 自算】
2023-二-1棱镜内两次反射后反向射出，求出射光强
如图，经两侧面反射后从斜面反方向射出，入射光强 I0，求 I。
1光路分解：正入射进入（一次透射）→ 两个侧面各全反射一次 → 再正入射射出（一次透射）。
2全反射时若无吸收、无散射，反射率 = 1，两次全反射不损失能量（这是全反射的特点，也是它被用作反射棱镜的原因）。
3进、出两个表面都是正入射，各有一次反射损失。设棱镜折射率 n：
R = [(n−1)/(n+1)]²，　透射率 T = 1 − R
I = I0 · T · 1 · 1 · T = I0(1 − R)²
理想情形（忽略表面反射损失、全反射无损耗）：I ≈ I0。
计入两表面反射：I = I0[1 − ((n−1)/(n+1))²]²（n = 1.5 时约 0.92 I0；n = 1.52 时约 0.919 I0）。

题干未给 n，两种写法都留——先写"全反射无损失 ⇒ I ≈ I0"，再补"若计表面反射则为 …"，不会丢分。
